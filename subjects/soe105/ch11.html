字符与字符串

Characters & Strings

来源 L13 · 术语 9 个

虚线下划线为术语；悬停查看中文、英文与释义，完整词典见“术语”。

本章从单个字符讲起：char 存什么、ASCII 怎么编码、<cctype> 提供哪些判断函数，再转到字符串的两种表示——以 '\0' 结尾的字符数组与 string 类，最后是 <cstring> 的库函数与 get/getline 的读法。

本章要点

  • char 存单个字符，比较用 <、<=、>、>=、==、!=，比较的其实是编码值。
  • ASCII 用 7 位编码 128 个字符：数字 48–57，大写 65–90，小写 97–122，控制字符 0–31 与 127。
  • <cctype> 的 isupper/islower/isalpha/isdigit/isalnum/isspace 返回“非零”表示真，tolower/toupper 做大小写转换。
  • cin >> 会跳过空白；要保留空格、制表与换行，必须用 cin.get 与 cout.put。
  • C 风格字符串是字符数组，以 '\0' 结尾；string 类自动管理长度，并支持比较、拼接、substr 与 find。
  • <cstring> 提供 strcpy、strcmp、strlen、strcat；get 不取走分隔符，getline 会取走并丢弃它。

11.1 char：一个字符的变量

字符类型char用来存放单个字符。声明写成 char resp;，赋值写成 resp = 'c';，常量声明写成 const char star = '*';——字符字面量用单引号，这一点与字符串的双引号必须分清。

讲义给的第一个例子是连续读四个字符：声明 char a, b, c, d; 然后 cin >> a >> b >> c >> d;，用户输入 1X2Y，四个变量依次拿到 '1'、'X'、'2'、'Y'；再 cout << a << b << c << d; 原样输出 1X2Y。这个例子说明输入流是按字符切分的，数字字符 '1' 与整数 1 是两回事。

字符可以比较，用的运算符与整数完全一样：<、<=、>、>=、==、!=。比较的依据不是“字母表顺序”这种模糊直觉，而是字符在编码表里的编号——这正是下一节 ASCII 的内容。理解了这一点，'a' < 'b' 成立、'A' < 'a' 也成立，就都不奇怪了。

易错

'1' 与 1 不相等：前者是编码为 49 的字符，后者是整数值 1。判断字符是不是数字要用 isdigit(c) 或 c >= '0' && c <= '9'，不能写 c >= 0。

11.2 ASCII：字符的编号表

ASCIIAmerican Standard Code for Information Interchange用 7 位编码 128 个字符；现代用法常把它们存进 8 位字节，并把最高位置 0。讲义把这张表分成三段来看：

  • 95 个可打印字符，编码 32–126，包括空格（32）、数字（48–57）、大小写英文字母（65–90 与 97–122）、标点与符号。
  • 33 个不可打印的控制字符，编码 0–31 与 127，用于格式与控制，例如 NULL（0）、BEL（7，响铃）、BS（8，退格 \b）、NL（10，换行 \n）、CR（13，回车）。
  • 它是 Unicode 前 128 个码点的基础，在编程、数据交换与遗留系统中仍是基本约定。
ASCII 中必须记住的几段编号
区间编码用途
数字 '0'–'9'48–57连续排列，'9' − '0' = 9
大写 'A'–'Z'65–90连续排列，共 26 个
小写 'a'–'z'97–122连续排列，与大写相差 32
空格32可打印，但 cin >> 会跳过它
控制字符0–31、127NULL、BEL、BS、NL、CR 等

这张表最实用的两个推论是：字符减字符可以得到数值（'7' − '0' = 7）；大小写之间只差 32，所以 tolower/toupper 只需要加减这个偏移。讲义后面 read_int 的写法，正是第一条推论的应用。

考点

记住三个起点：'0' = 48、'A' = 65、'a' = 97；并记住数字、大写、小写各自连续。给出任一字符就能推出同组其它字符的编码。

L13 p.3–4

11.3 <cctype>：字符判断与转换

标准库 <cctype> 提供了一组针对字符的小函数。讲义的表述有一个共同点：判断类函数“返回非零”表示条件成立，而不是严格返回 true——在 C 里它们返回 int。

  • isupper(c)：c 是大写字母时返回非零。
  • islower(c)：c 是小写字母时返回非零。
  • isalpha(c)：islower(c) 或 isupper(c) 成立时返回非零。
  • isdigit(c)：c 是数字字符时返回非零。
  • isalnum(c)：isalpha(c) 或 isdigit(c) 成立时返回非零。
  • isspace(c)：c 是空格、换行或制表符时返回非零。
  • tolower(c)：大写则返回对应小写，否则原样返回 c。
  • toupper(c)：小写则返回对应大写，否则原样返回 c。

这组函数的返回值可以直接放在 if 条件里用，因为“非零即真”。tolower/toupper 的“否则原样返回”也很重要：它们不会把数字或标点变成别的东西，可以放心地对任意字符调用。

辨析

isalnum 不是“字母或数字以外的都算”，而是“字母或数字才返回非零”。空格、下划线、标点都会让它返回 0。判断“是不是分隔符”要用 isspace 或直接比较。

L13 p.4–5

11.4 三个字符程序：判断、响铃与随机

第一个例子是自己实现一个 islower：函数体只有一句 if (c >= 'a' && c <= 'z') return 1; else return 0;。主程序读一个字符，调用它并分别输出“是小写字母”或“是大写字母”。这个例子把 ASCII 的“连续排列”用上了——小写字母正好占据 'a' 到 'z' 这一段连续编码。

int islower(char c) {
    if (c >= 'a' && c <= 'z') return 1;
    else return 0;
}

第二个例子只有一行：cout << '\7';。反斜杠加数字是八进制转义，'\7' 对应编码 7，也就是 BEL，终端会发出一声提示音。这是控制字符在代码里的直接用法。

第三个例子输出随机字符：先 srand(time(0)) 用当前时间初始化随机数发生器，再取 r = rand() % 26 得到 0–25，最后 c = 'a' + r。因为小写字母编码连续，'a' 加上偏移就落在 'a'–'z' 之间。这个技巧在需要随机生成名字、随机选字母时很好用。

易错

'\7' 是八进制转义（编码 7），不是十进制 7、也不是字符 '7'。字符 '7' 的编码是 55。写 '\7' 得到响铃，写 '7' 得到数字七的字形。

L13 p.5–7

11.5 空白字符：cin >> 与 cin.get 的分工

讲义先点明一个容易被忽略的行为：cin >> c 会跳过任何空白——空格、制表符、换行都算。它给的例子是用 while (c != '\n') 循环读字符并输出，输入 a b c d，输出却是 abcd，中间的空格全被吃掉了。

char c = ' ';
while (c != '\n') {
    cin >> c;      // skips whitespace
    cout << c;
}

要保留空白，就得换成成员函数member function式的读取：cin.get(char &c) 读入一个字符，其余内容留在流里；cout.put(char) 向标准输出写一个字符。把循环体换成 cin.get(c); cout.put(c);，同样的输入就原样输出 a b c d，空格一个不少。

这一对函数的意义在于“逐字符处理”：读文件、统计字符、解析格式时，往往需要知道每一个空格与换行的位置，而不是让输入流替我们跳过它们。讲义把 get/put 归入“读取字符时有用的 I/O 与文件流函数”，后面第 14 章的文件读写会再次用到。

考点

cin >> 提取的是“符合目标类型的一个 token”，会自动跳过前导空白；cin.get 提取的是“下一个字节”，不做任何跳过。要数空格就用 get。

L13 p.8–9

11.6 字符转数字：逐位构造与溢出

讲义给了一个把一行字符里的数字拼成整数的函数 read_int。它用 do-while 逐字符读取，遇到数字字符就把当前值乘 10 再加新的一位，直到读到换行为止。

int read_int() {
    const char delimiter = '\n';
    char next = ' ';
    int digit;
    int value = 0;
    do {
        cin.get(next);                 // read in the character
        if (isdigit(next)) {           // update value if input is a digit
            digit = (int)(next - '0');
            value = 10 * value + digit;
        }
    } while (next != delimiter);
    return value;
}

三处细节值得注意。第一，next − '0' 把字符编码差转成数值：'7' 的编码是 55，'0' 是 48，相减得 7。第二，value = 10 * value + digit 是“左移一位再补个位”的标准写法，读 1、2、3 会依次得到 1、12、123。第三，非数字字符被直接忽略，所以输入 1a234 得到 1234。

讲义还展示了两个运行结果：输入 1234567890 输出 1234567890，正常；输入 12345678900 却输出 −539222988。幻灯片上标着“Why?”，答案是溢出overflow——这个数已经超出 int 能表示的范围，高位被截断，结果变成一个负数。这段代码没有任何检查，溢出了也照算不误。

易错

value = 10 * value + digit 不会自己判断越界。输入位数超过 int 的表示能力时，得到的是一个“看起来合法”的错误数值，而不是报错。需要处理长数字时，必须自己检查范围或换更宽的类型。

L13 p.10–12

11.7 C 风格字符串：字符数组加 '\0'

讲义把字符串定义为“以空字符 '\0'（即 char(0)）结尾的字符数组”。这个结尾标记是整套规则的核心：函数靠它判断字符串到哪里结束，数组的容量则可能比字符串长。

char nameA[20] = "Peter Pan";
cout << "nameA: " << nameA << endl;
for (int i = 0; i < 20; i++) {
    printf("nameA[%i]='%c'\n", i, nameA[i]);
}

这段代码能打印整个名字，是因为 cout 遇到 '\0' 就停；而下面的循环把 20 个格子全打出来，可以看到 "Peter Pan" 只占前 9 个字符，第 9 个格子是 '\0'，后面还有未使用的空间。讲义在幻灯片上标注：数组大小必须事先给定。

对照的 string 版本是 string nameS = "Peter Pan";。它同样能用下标访问字符（nameS[i]），但长度由变量自己记录——讲义的原话是“数组大小会自动确定，并作为属性存在变量内部”，取长度用 nameS.length()，循环上界可以直接写 i < nameS.length()，不必事先猜一个 20。

辨析

char nameA[20] 的 20 是“容量”，strlen 之类得到的是“内容长度”，两者不是一回事。容量不够时字符串会被截断，容量富余时尾部是一片没用到的格子。

L13 p.13–14

11.8 string 类：比较、拼接、子串与查找

string 不是 C/C++ 的内置类型，用之前要包含 <string> 库。它的操作比字符数组丰富得多：用 <、<=、>、>=、==、!= 比较字符串，用 + 拼接（连接）字符串，用 s.c_str() 取回一个指向“以 '\0' 结尾的字符数组”的 const char*，用 s.substr(position, size) 取从 position 开始、长度为 size 的子串，用 s.find(subs) 找子串出现的位置。

find 有一个必须记住的失败返回值：如果 subs 不在 s 中，它返回 std::npos——讲义的解释是“一个比字符串中任何合法位置都大的数”。因此判断“找到没有”不能写 if (pos == 0)，而要写 if (pos == string::npos) 或与 npos 比较。

讲义的例子把常用操作串在一起：s = "Top"、t = "ten"，w = s + t 得到 "Topten"，w[5] 是 'n'（下标从 0 开始数：T、o、p、t、e、n）；s < t 成立，因为按字典序比较时 "Top" 排在 "ten" 之前（大写字母的编码比小写小）；s + t == w 成立；在 x = "Top 10 Uses for Strings" 里 x.find("Uses") 返回 7；x.substr(12, 7) 返回 "for Str"。

把这些结果与上一节的字符数组对照，可以看出 string 的优势：不必预先定容量、不必手工维护 '\0'、比较与拼接都有现成的运算符。代价是要记得包含头文件，并且在需要传给 C 风格接口时用 c_str() 转换。

考点

substr(position, size) 的两个参数是“起点 + 长度”，不是“起点 + 终点”；find 失败返回 npos，不是 −1，也不是 0。

L13 p.14–17

11.9 <cstring> 与 get/getline

处理 C 风格字符串时，标准库 <cstring> 提供了一组函数：strcpy(dest, src) 把 src 复制到 dest；带第三个参数的版本最多复制 n 个字符；strcmp 比较两个字符串，相等返回 0；strlen 返回字符串长度；strcat 把 src 追加到 dest 末尾。讲义提醒，可以用 s.c_str() 从 string 对象取出字符数组，再交给这些函数。

输入方面有四个容易混淆的函数。get(char str[], int len, char delim) 最多读 len − 1 个字符，或读到下一个 delim、或文件结束为止，然后自动在 str 末尾补 '\0'；get(str, len) 等价于把 delim 取 '\n'；getline(str, len, delim) 与 get 相同，区别是它会把随后的那个 delim 也取走并丢弃；getline(str, len) 等价于 delim 为 '\n'。

char str[20], buffer[100];
cin.get(str, 20);            // up to 19 chars, stops at '\n'
cin.get(str, 20, '/');       // stops at '/'
cin.getline(str, 20, '/');   // stops at '/' and discards it
cin.getline(buffer, 100);    // stops at '\n' and discards it

“是否丢弃分隔符”看起来只是细节，实际会决定下一次读取拿到什么：get 把 '\n' 留在流里，下一次读字符会先读到这个换行；getline 把它取走，下一行才能正常读。混用两者时如果发现程序“莫名其妙读到了空行”，先检查这里。

“最多 len − 1 个字符”也值得记住：参数 len 是缓冲区容量，必须给 '\0' 留一个位置，所以实际能存的内容比 len 少一个。

易错

get 与 getline 的 len 是缓冲区大小，不是要读的字符数；能读到的上限是 len − 1。写成 get(str, 20) 却期待读到 20 个字符，会少一个。
