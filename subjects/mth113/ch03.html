本讲把第 2 周的“事件概率”压缩成“随机变量的分布”：用概率质量函数 PMF 描述离散取值，用累积分布函数 CDF 描述累积概率，再用期望与方差概括分布的中心和离散程度。

本章要点

  • 随机变量是把样本空间映射到实数的函数，用大写字母表示变量、小写字母表示取值。
  • 离散随机变量的支撑集是可数取值集合；PMF 必须非负且总和为 1。
  • PMF 给出单点概率，CDF 给出累积概率 F(x) = P(X ≤ x)，两者可互相还原。
  • 离散 CDF 是阶梯函数，跳跃高度等于该点的 PMF 值。
  • 期望 E(X) = Σxp(x) 是概率加权平均，不一定是可能取值。
  • E[g(X)] = Σg(x)p(x)，期望的线性性不需要独立性。
  • Var(X) = E(X2) − [E(X)]2；线性变换 Var(a + bX) = b2Var(X)。
  • 方差相加需要独立或零协方差，期望相加不需要。

3.1 从样本空间到随机变量

第 2 周用事件与集合描述随机现象，但逐个列出结果往往很繁琐。讲义用工厂检查三件产品的例子引入简化：每件产品可能是次品 D 或合格 A，样本空间

S = {AAA, AAD, ADA, DAA, ADD, DAD, DDA, DDD}

与其记住完整结果，不如定义 X = 三件产品中的次品数。于是 AAA 对应 0；AAD、ADA、DAA 对应 1；ADD、DAD、DDA 对应 2；DDD 对应 3。八个结果被压缩成四个数值。

随机变量random variable定义为把样本空间中每个结果映射到一个数值的函数：X : S → ℝ。要区分“结果”与“随机变量的值”：结果是实验的详细结局，例如 ADA；随机变量的值是由结果算出的数，例如 X(ADA) = 1。

记号约定：随机变量用大写 X、Y、Z，可能取值用小写 x、y、z。“X = 2”本身是一个事件，表示所有使随机变量等于 2 的结果；P(X = 2) 是这个事件的概率。三件产品例中 {X = 2} = {ADD, DAD, DDA}。

随机变量在观测之后不再随机，它的“随机性”来自观测前不知道哪个结果会发生。这个理解对后面区分“统计量是随机变量”很关键。

考点

随机变量是函数，不是“随机的数”。写 P(X = 2) 时要能回到样本空间，指出它对应哪些结果。

W3 p.5–8

3.2 离散与连续随机变量、支撑集

随机变量先分离散与连续。离散随机变量的可能取值是有限或可数无限个；连续随机变量取值是实数区间。离散用概率质量函数probability mass function建模，连续用概率密度函数probability density function建模。离散常问 P(X = 3)，连续常问 P(2 < X < 5)。离散例子有缺陷数、来电数、骰子点数；连续例子有时间、重量、温度、寿命。

支撑集support是随机变量以正概率取到的全部值：

supp(X) = {x : P(X = x) > 0}

例：掷一颗骰子，supp(X) = {1, 2, 3, 4, 5, 6}；三件产品中的次品数，supp(Y) = {0, 1, 2, 3}；中午前收到的邮件数，supp(N) = {0, 1, 2, …}。

支撑集的边界有时取决于定义。讲义练习中“购买前点击次数”可以定义为从 1 开始，也可以定义为从 0 开始，取决于是否允许“零次点击就购买”。定义不同，支撑集不同，PMF 的表达也随之不同。建模前先确定随机变量到底数什么。

易错

支撑集只包含正概率的取值。若某值概率为 0，它不应出现在 PMF 表中；但连续变量在任何单点的概率都为 0，不能用同一标准处理。

W3 p.9–10、13–14

3.3 分布、PMF 与概率表

分布distribution告诉我们概率如何分配给随机变量的各个取值。离散随机变量的分布可用四种方式表示：概率表、概率质量函数 p(x)、概率直方图、累积分布函数 F(x)。样本空间可能很复杂，但 X 的分布可以简单得多。

讲义例：每件产品独立地以 0.10 的概率为次品，检查三件，X = 次品数。则

三件产品的次品数分布（p = 0.10）
x对应结果p(x)
0AAA0.93 = 0.729
1DAA, ADA, AAD3(0.1)(0.9)2 = 0.243
2DDA, DAD, ADD3(0.1)2(0.9) = 0.027
3DDD0.13 = 0.001

四行概率之和为 0.729 + 0.243 + 0.027 + 0.001 = 1。原本八个详细结果被压缩成四个取值，每组内部的组合数决定了该取值的概率。

概率质量函数probability mass function简写为 PMF：p(x) = P(X = x)。它把“概率质量”分配到每个可能取值上。离散随机变量单点概率可以为正，这一点与连续变量截然不同。

辨析

“分布”是整体指派规则，“PMF”是它的函数形式，“概率表”是它的表格呈现。三者指同一对象的不同表达，考试中不要把它们当成三个不同概念。

W3 p.11–15

3.4 PMF 的两条检验与归一化常数

函数 p(x) 是合法 PMF，当且仅当

p(x) ≥ 0 对所有 x；   Σx∈supp(X) p(x) = 1

两条都要满足。讲义反例：x = 0,1,2,3 时 p(x) = 0.15, 0.40, 0.50, 0.10，每个数都在 0 与 1 之间，但总和 1.15 ≠ 1，所以不是合法 PMF。另一个反例总和为 1 却含负概率 −0.10，同样不合法。

正例：x = 0,1,2,3 时 p(x) = 0.20, 0.35, 0.30, 0.15，总和 1.00 且全部非负，合法。

有时 PMF 含未知常数 c，用“总和为 1”反解。设 p(x) = cx，x = 1,2,3,4。则

Σ p(x) = c(1 + 2 + 3 + 4) = 10c = 1  ⇒  c = 0.1

于是 p(x) = 0.1x。这个分布随 x 线性上升，画成概率直方图时柱高依次为 0.1、0.2、0.3、0.4。

考点

只检查“每个概率小于 1”不够，必须同时检查非负与总和为 1。求归一化常数就是解 Σp(x) = 1。

W3 p.16–20、26–27

3.5 用 PMF 求概率、补集与离散均匀分布

若事件用 X 的取值描述，就把该事件包含的所有 x 的 PMF 值相加：

P(X ∈ A) = Σx∈A p(x)

对 p(x) = 0.1x，x = 1,2,3,4：P(X ≥ 3) = 0.3 + 0.4 = 0.7；P(X 为偶数) = 0.2 + 0.4 = 0.6；P(1 < X < 4) = p(2) + p(3) = 0.5。注意严格不等号会排除端点。

当事件包含很多取值而补集很简单时，用补集更快：若 supp(X) = {0,1,2,3,4,5}，则 P(X ≥ 1) = 1 − P(X = 0)。若 P(X = 0) = 0.18，则结果为 0.82。

掷两颗公平骰子，X = 点数和。虽然 36 个有序对等可能，但 X 的 11 个取值并不等可能：和为 2 与 12 各只有 1 种，和为 7 有 6 种。分布表为 p(2) = 1/36，p(3) = 2/36，…，p(7) = 6/36，…，p(12) = 1/36。分布关于 7 对称，7 最可能，两端最小。

离散均匀分布discrete uniform distribution是另一类简单模型：若 X 在 {a, a+1, …, b} 上等可能，则

p(x) = 1 / (b − a + 1)，  x = a, …, b

一颗公平骰子即 p(x) = 1/6。两颗骰子的“点数和”不是离散均匀，因为各和对应的底层结果数不同。

易错

“结果等可能”不等于“随机变量的取值等可能”。36 个有序对等可能，但点数和 2 到 12 各有不同数目的底层结果，不能按 1/11 计算。

W3 p.21–25

3.6 累积分布函数 CDF 的定义与构造

累积分布函数cumulative distribution function对任意随机变量定义为

F(x) = P(X ≤ x) = Σt≤x p(t)

CDF 从左侧累积概率。以 x = 0,1,2,3 时 p(x) = 0.10, 0.30, 0.40, 0.20 为例：F(0) = 0.10，F(1) = 0.40，F(2) = 0.80，F(3) = 1.00。F(2) = P(X ≤ 2) = 0.10 + 0.30 + 0.40 = 0.80。

完整的 CDF 要分段写出，并且必须覆盖支撑集之外：

F(x) = 0 (x < 0)；0.10 (0 ≤ x < 1)；0.40 (1 ≤ x < 2)；0.80 (2 ≤ x < 3)；1 (x ≥ 3)

离散随机变量的 CDF 是阶梯函数step function，在每个可能取值处向上跳，跳的高度等于该点的 p(x)。跳跃点之间保持水平。

考点

写 CDF 必须写全三段：支撑集左侧为 0，右侧为 1，中间逐段累积。只写中间部分会丢分。

W3 p.28–31

3.7 CDF 的性质与由 CDF 反推 PMF

任何 CDF 都满足四条性质：0 ≤ F(x) ≤ 1；F(x) 非减；x → −∞ 时 F(x) → 0；x → ∞ 时 F(x) → 1。对离散随机变量还有第五条：跳跃只发生在正概率的取值处，跳跃高度等于 p(x)。

反过来，知道 CDF 就能用相邻跳跃差还原 PMF。对取整数值的随机变量：

p(x) = F(x) − F(x − 1)

对上面的例子：p(0) = 0.10 − 0 = 0.10；p(1) = 0.40 − 0.10 = 0.30；p(2) = 0.80 − 0.40 = 0.40；p(3) = 1.00 − 0.80 = 0.20。所有跳跃高度之和为 1。

这个“跳跃即概率”的视角在连续情形会变成“密度不是概率”，但在离散情形非常直观：CDF 平坦的地方没有概率，抬升的地方才有概率质量。

辨析

F(x) 是“≤ x 的累计概率”，不是“等于 x 的概率”。p(x) 才是单点概率；两者相差一个累积操作。

W3 p.32–33

3.8 用 CDF 计算概率与不等式陷阱

对任意随机变量，P(X ≤ a) = F(a)；对离散随机变量，区间概率为

P(a < X ≤ b) = F(b) − F(a)

例：F(1) = 0.40、F(3) = 1.00，则 P(1 < X ≤ 3) = 0.60。

离散情形必须小心严格与非严格不等号。对整数值随机变量：

P(X < 2) = P(X ≤ 1) = F(1)；  P(X ≤ 2) = F(2)
P(X > 2) = 1 − F(2)；  P(X ≥ 2) = 1 − F(1)

最后一条最易错：P(X ≥ 2) 包含 X = 2，所以要从 F(1) 而不是 F(2) 处取补。讲义把它列为 Week 3 的头号错误之一。

综合例：x = 0 到 4 时 p(x) = 0.05, 0.15, 0.35, 0.30, 0.15，累积得 F = 0.05, 0.20, 0.55, 0.85, 1.00。于是 P(X ≤ 2) = 0.55；P(X > 2) = 1 − 0.55 = 0.45；P(1 < X ≤ 3) = F(3) − F(1) = 0.85 − 0.20 = 0.65。

易错

对整数值 X，P(X ≥ a) = 1 − F(a − 1)，不是 1 − F(a)。后者会把 X = a 错误地排除。

W3 p.34–38

3.9 期望：概率加权平均

期望expected value（均值）定义为

E(X) = μX = Σx x p(x)

它是取值的概率加权平均，描述分布的中心。长期解释：把试验重复很多次，X 的平均值趋向 E(X)。

掷一颗公平骰子，E(X) = (1+2+3+4+5+6)/6 = 3.5。3.5 不是骰子能掷出的结果，这说明期望不必是可能取值，它只是长期平均。

缺陷数例：x = 0 到 4 时 p(x) = 0.50, 0.25, 0.15, 0.07, 0.03。则 E(X) = 0(0.50) + 1(0.25) + 2(0.15) + 3(0.07) + 4(0.03) = 0 + 0.25 + 0.30 + 0.21 + 0.12 = 0.88。长期看，每批平均 0.88 个缺陷。

计算时保留一行 xp(x) 再加总，可显著减少算术错误。讲义把它称为 expectation table 的考试技巧。

考点

期望用 x 乘 p(x) 再求和，不是把 x 简单平均。结果为 0.88 时要说“长期平均每批 0.88 个缺陷”，不能说“每批有 0.88 个缺陷”。

W3 p.40–43、47

3.10 函数的期望、线性性与指示变量

若 Y = g(X)，不必先求 Y 的分布，可直接用

E[g(X)] = Σx g(x) p(x)

例：维修成本 C = 50 + 120X，则 E(C) = Σ (50 + 120x)p(x)。用线性性更快：

E(a + bX) = a + b E(X)；   E(X + Y) = E(X) + E(Y)

线性性不需要独立性，只要期望存在。缺陷数例 E(X) = 0.88，若检验成本 C = 200 + 80X，则 E(C) = 200 + 80(0.88) = 270.4。这不是每批的实际成本，而是长期平均成本。

公平游戏：付 5 元玩一次，以 0.2 概率赢 20、以 0.8 概率赢 0。净收益 G = 奖金 − 5，取 15 与 −5，E(G) = 15(0.2) + (−5)(0.8) = 3 − 4 = −1，对玩家不公平，每玩一次平均亏 1。若奖金 20 的概率为 0.2，票价 t 使 E(G) = 4 − t = 0，则公平票价 t = 4。

指示变量indicator random variable把事件概率转成期望：IA = 1（A 发生）、0（A 不发生），则 E(IA) = 1·P(A) + 0·P(Ac) = P(A)。五个独立设备各以 pi 通过，通过数 X = I1 + … + I5，则 E(X) = p1 + … + p5，不需要各设备概率相等。

易错

E(X2) ≠ [E(X)]2。前者要用 x2p(x) 求和；只有常数随机变量两者才相等。

W3 p.44–50

3.11 方差、标准差与线性变换

方差variance定义为

Var(X) = σX2 = E[(X − μX)2] = Σ (x − μX)2 p(x)

标准差 SD(X) = √Var(X)。方差衡量分布围绕均值的离散程度，标准差的单位与原变量相同。

计算常用捷径：

Var(X) = E(X2) − [E(X)]2，   E(X2) = Σ x2p(x)

缺陷数例：E(X) = 0.88，E(X2) = 0(0.50) + 1(0.25) + 4(0.15) + 9(0.07) + 16(0.03) = 0 + 0.25 + 0.60 + 0.63 + 0.48 = 1.96。于是 Var(X) = 1.96 − 0.882 = 1.1856，SD(X) ≈ 1.089。解释：长期平均每批 0.88 个缺陷，典型批次围绕这个平均约波动 1.09 个缺陷。

线性变换：

Var(a + bX) = b2 Var(X)，   SD(a + bX) = |b| SD(X)

加常数只平移分布，不改变离散程度；乘以 b 使离散程度变为 |b| 倍。成本 C = 200 + 80X 时，E(C) = 270.4，Var(C) = 802(1.1856) = 7587.84，SD(C) = 80(1.089) ≈ 87.12。

为什么用平方偏差：简单偏差的期望为 E(X − μ) = 0，正负会抵消；平方偏差非负且给远离均值的值更大权重。讲义另用两个同均值分布说明：A 在 1,2,3 上取 0.25/0.50/0.25，B 在 0,2,4 上取 0.25/0.50/0.25，均值都为 2，但 Var(A) = 0.5、Var(B) = 2，说明均值不能描述变异性。

考点

方差公式中系数要平方，加常数不影响方差。先算 E(X2) 再减均值平方，比逐项算 (x−μ)2 更不容易出错。

W3 p.53–61

3.12 随机变量之和、综合案例与常见错误

期望对加法总是线性：E(X + Y) = E(X) + E(Y)，E(aX + bY) = aE(X) + bE(Y)。例：线上销售期望 120 件、零售期望 80 件，总销售期望 200 件。

方差相加则需要独立（或零协方差）：若 X、Y 独立，

Var(X + Y) = Var(X) + Var(Y)；   Var(aX + bY) = a2Var(X) + b2Var(Y)

两条生产线：X 的 E = 2、Var = 1.5；Y 的 E = 3、Var = 2.2。若独立，总缺陷 T = X + Y 有 E(T) = 5，Var(T) = 3.7，SD(T) ≈ 1.92。

综合案例：某客服中心用 X 表示顾客购买后第一年的服务来电数，p(0) = 0.60、p(1) = 0.25、p(2) = 0.10、p(3) = 0.04、p(4) = 0.01。检验：总和为 1 且非负，合法。P(X ≥ 2) = 0.10 + 0.04 + 0.01 = 0.15。E(X) = 0.61，E(X2) = 1.17，Var(X) = 1.17 − 0.3721 = 0.7979，SD ≈ 0.893。若每年来电成本 C = 40 + 180X，则 E(C) = 40 + 180(0.61) = 149.8，Var(C) = 1802(0.7979) ≈ 25851.96，SD(C) ≈ 160.74。

讲义列出七类错误：忘记检验概率和为 1；混淆 p(x) 与 F(x)；把 P(X ≥ a) 写成 1 − F(a)；把期望当成必然结果；忘记平方系数；不检查独立就加方差；报告数字不带情境与单位。

易错

期望线性性无条件成立，方差可加性需要独立。若题目只说“两个随机变量”，不能默认独立；必须先确认或由上下文推出。
