连续随机变量

本讲把概率从“点上的质量”换成“区间上的面积”：连续随机变量用概率密度函数 PDF 描述，概率由定积分或密度曲线下的面积给出，累积分布函数 CDF 把区间概率变成减法，期望与方差则把求和换成积分。

本章要点

  • 连续随机变量的取值填满一个区间，单点概率 P(X = a) = 0，端点是否包含不影响概率。
  • PDF 必须非负且全轴积分为 1；密度高度不是概率，面积才是概率。
  • P(a < X < b) = ∫ab f(x)dx；均匀分布的密度是常数 1/(b − a)。
  • CDF F(x) = ∫−∞x f(t)dt，且 P(a < X < b) = F(b) − F(a)；PDF 是 CDF 的导数。
  • 分位数由 F(qp) = p 解出，中位数解 F(m) = 0.5。
  • E(X) = ∫xf(x)dx，Var(X) = E(X2) − [E(X)]2；均匀分布 E = (a+b)/2，Var = (b−a)2/12。
  • 分段密度要分区间积分；写 CDF 时支撑集外要补 0 与 1。

4.1 连续随机变量与离散随机变量的差别

许多量是测量出来的而不是数出来的：等公交的时间、冷柜温度、瓶装饮料的灌装量、元件寿命、以千件计的周需求。这类量的可能取值填满一个区间，讲义把它们建模为连续随机变量continuous random variable。现实中测量会被四舍五入，但底层变量常按连续处理。

离散与连续随机变量的对照
维度离散连续
典型来源计数测量
可能取值孤立点区间
单点概率可以为正恒为 0
概率计算概率求和密度积分
核心函数PMF p(x)PDF f(x)
CDFF(x) = Σt≤x p(t)F(x) = ∫−∞x f(t)dt

最关键的思维转变：连续变量的概率不挂在单点上。P(X = a) = 0，而 P(a < X < b) > 0。因此连续情形问的是“2 到 4 分钟之间”，而不是精确到“3.000000 分钟”。

讲义例：班车每 10 分钟一班，学生在两班之间随机到达。令 X = 等待分钟数，则 0 < X < 10；若区间内各等待时间等可能，就建模为 (0, 10) 上的均匀分布。这是最简单的连续模型：区间上密度恒定。

考点

判断离散还是连续看“计数还是测量”，也看“单点是否有正概率”。连续变量在任何单点的概率都是 0，这是后面所有积分公式的出发点。

W4 p.5–9

4.2 从直方图到密度曲线：PDF 的两条条件

把测量精度不断提高：先四舍五入到整数，直方图的柱很宽；精确到一位小数，柱变窄；继续精确，直方图逐渐接近一条光滑曲线。这条曲线就是密度曲线density curve：它在某区间上的面积等于随机变量落入该区间的概率。

函数 f 是概率密度函数probability density function（PDF），当且仅当

f(x) ≥ 0 对所有 x；   ∫−∞∞ f(x)dx = 1

对任意区间 (a, b)，

P(a < X < b) = ∫ab f(x)dx

PDF 给出的是“密度”，积分才给出“概率”。f(x) 较大处，x 附近的取值比密度较小处更可能；但 f(x) 本身不是 P(X = x)。对很小的区间，P(x < X < x + Δx) ≈ f(x)Δx，这说明密度是“单位长度的概率”。

易错

密度高度可以大于 1。例如 (0, 0.2) 上的均匀密度为 5，但它在整个支撑集上的面积为 1。概率必须落在 0 与 1 之间，密度不必。

W4 p.10–16

4.3 面积即概率与均匀密度

讲义用图示强调：P(2 < X < 4) 就是曲线在 2 到 4 之间的阴影面积。这个“面积”视角让许多题不必硬算积分，用矩形或三角形面积即可。

若 X 在 (a, b) 上均匀分布，则

f(x) = 1/(b − a)，a < x < b；  其他处为 0

合法性来自矩形面积：(b − a) × 1/(b − a) = 1。均匀意味着区间上密度恒定，任何等长的小区间概率相同。

班车例：X ~ Uniform(0, 10)，f(x) = 1/10。则

P(3 < X < 7) = ∫37 (1/10)dx = 4/10 = 0.4

几何上就是一个宽 4、高 0.1 的矩形面积。均匀分布的概率与区间长度成正比，这是它最重要的性质。

由此还可直接得到均匀分布的中位数：使 F(m) = 0.5 的位置正是区间中点 (a+b)/2。均匀分布中位数与均值重合，这是对称分布的共同特征；但它不是所有连续分布的通性，后面 f(x) = x/8 的例子就会看到均值、中位数与区间中点三者分开。

考点

均匀分布的概率 = 区间长度 / 总长度。先确认区间落在支撑集内，再算长度比，不必每次积分。

W4 p.17–19、29

4.4 为什么 P(X = a) = 0，端点为何无关

概率是面积，单点没有宽度，所以

P(X = a) = ∫aa f(x)dx = 0

由此，对 a < b，

P(a < X < b) = P(a ≤ X < b) = P(a < X ≤ b) = P(a ≤ X ≤ b)

均匀 (0, 10) 中 P(3 < X < 7) 与 P(3 ≤ X ≤ 7) 都等于 0.4。改变端点是否包含，只改变一条零宽度的线，不改变面积。

这一点与离散情形形成鲜明对照：离散变量 P(X = 2) 可能等于 0.3，所以 P(X < 2) 与 P(X ≤ 2) 可能不同；连续变量两者总是相同。考试中看到连续分布却纠结“要不要减一个点”，说明还没完成这个思维转变。

易错

P(X = a) = 0 不表示“X = a 不可能发生”，只表示在连续模型下该单点的概率测度为零。模型是理想化，事件仍可能发生。

W4 p.20–21

4.5 求归一化常数：让总面积为 1

题目常给出含未知常数 k 的密度，要求使它合法。做法固定：令全轴积分为 1，解出 k；再确认非负。

例 1：f(x) = k（2 < x < 6），其他为 0。则

1 = ∫26 k dx = 4k  ⇒  k = 1/4

这是区间上的常数密度，即均匀分布。

例 2：f(x) = kx（0 < x < 4），其他为 0。则

1 = ∫04 kx dx = k[x2/2]04 = 8k  ⇒  k = 1/8

密度随 x 增大而增大，所以较大的取值比较小的取值更可能。求 P(1 < X < 3)：∫13 (x/8)dx = [x2/16]13 = 9/16 − 1/16 = 0.5。

例 3：三角密度 f(x) = 2(1 − x)（0 < x < 1）。检验 ∫01 2(1−x)dx = [2x − x2]01 = 1。密度在 0 附近最高，线性下降到 1 处为 0。计算 P(1/4 < X < 1/2) 得 [2x − x2]1/41/2 = 3/4 − 7/16 = 5/16。

考点

归一化常数永远由“总积分等于 1”解出。解完要回代检查非负；若密度在支撑集内变负，即使积分为 1 也不合法。

W4 p.22–26

4.6 先用几何、再上微积分；高度不是概率

讲义建议先看图形再决定是否积分：均匀密度用矩形面积；线性密度用三角形或梯形面积；分段常数密度用若干矩形面积之和。例：X ~ Uniform(0, 20)，f(x) = 1/20，则 P(7 < X < 12) = (12 − 7)/20 = 0.25。

“高度不是概率”的经典反例：f(x) = 2(1 − x)（0 < x < 1），在 x = 0.25 处 f(0.25) = 1.5。1.5 不可能是概率，但它是合法的密度高度；该点附近小区间的面积约 1.5Δx，仍然小于 1。

活动判断四个函数是否可为 PDF：f(x) = 3x2（0 < x < 1）合法，积分为 1 且非负；f(x) = x（0 < x < 1）不合法，积分为 1/2；f(x) = 1/5（2 < x < 7）合法，面积 (7−2)(1/5) = 1；f(x) = 2 − x（0 < x < 3）不合法，x > 2 时函数为负。

易错

只检查“积分为 1”不够，还要检查“处处非负”。f(x) = 2 − x 在 (0,3) 上积分虽为 1.5，但后半段为负，绝不能当密度。

W4 p.27–30

4.7 连续 CDF 与区间概率

连续随机变量的累积分布函数cumulative distribution function为

F(x) = P(X ≤ x) = ∫−∞x f(t)dt

它给出 x 左侧的累积面积。若 a < b，则 P(a < X < b) = F(b) − F(a)：用 b 左侧面积减去 a 左侧面积，剩下的正是中间部分。

均匀分布 X ~ Uniform(a, b) 的 CDF 为

F(x) = 0 (x ≤ a)；(x − a)/(b − a) (a < x < b)；1 (x ≥ b)

对 X ~ Uniform(0, 10)，F(x) = x/10（0 < x < 10）。再以 f(x) = x/8（0 < x < 4）为例，F(x) = ∫0x (t/8)dt = x2/16。于是 P(1 < X < 3) = F(3) − F(1) = 9/16 − 1/16 = 1/2；P(X > 2) = 1 − F(2) = 1 − 4/16 = 3/4。

CDF 的性质：0 ≤ F(x) ≤ 1；非减；左端趋于 0、右端趋于 1；连续随机变量的 F 连续，没有跳跃。PDF 可以分段甚至不连续，但 CDF 一定连续。反过来，若 F 可导，则 f(x) = F′(x)。例如 F(x) = x3（0 < x < 1），则 f(x) = 3x2。

考点

写连续 CDF 必须补齐三段：x 小于支撑集下限时为 0，落在支撑集内用积分，大于上限时为 1。只写中间一段是常见失分点。

W4 p.33–41

4.8 分位数与中位数：解 F(q) = p

第 p 分位数quantile qp 满足 F(qp) = p。中位数是 q0.5，第一四分位数是 q0.25，第三四分位数是 q0.75。连续分布的分位数靠解方程得到，不像离散那样只能取到跳跃点。

对 f(x) = x/8（0 < x < 4），F(x) = x2/16。中位数 m 满足 m2/16 = 0.5，故 m2 = 8，m = 2√2 ≈ 2.828。支撑集中点是 2，但中位数大于 2，因为密度在较大的 x 处更高。

第 70 百分位：q0.702/16 = 0.70，故 q0.70 = 4√0.70 ≈ 3.347。约 70% 的概率落在 3.347 以下。

活动：f(x) = 3x2（0 < x < 1）。F(x) = x3；P(0.2 < X < 0.8) = 0.83 − 0.23 = 0.512 − 0.008 = 0.504；中位数解 m3 = 0.5，m = 0.51/3 ≈ 0.794。

易错

中位数不是“支撑集的中点”，也不是“密度的最大值点”。它由累积面积一半决定；密度右偏时中位数会大于区间中点。

W4 p.42–46

4.9 连续随机变量的期望

连续情形把求和换成积分：

E(X) = ∫−∞∞ x f(x)dx

它仍是概率加权平均，只是权重由密度给出。均匀分布 X ~ Uniform(a, b)：

E(X) = ∫ab x/(b−a) dx = (b2 − a2)/[2(b−a)] = (a + b)/2

即区间中点。这符合直觉：密度恒定，重心在中间。

对 f(x) = x/8（0 < x < 4），

E(X) = ∫04 x·(x/8)dx = ∫04 x2/8 dx = [x3/24]04 = 64/24 = 8/3 ≈ 2.667

均值 2.667 高于中点 2，因为密度随 x 增大，较大的值贡献更多。

函数的期望同样直接积分：

E[g(X)] = ∫ g(x) f(x)dx；   E(X2) = ∫ x2f(x)dx

线性性照旧：E(a + bX) = a + bE(X)。求 g(X) 的期望不需要先求 g(X) 的分布。

考点

期望积分里乘的是 x，不是 x2；求 E(X2) 时才乘 x2。均匀分布的期望可直接用 (a+b)/2。

W4 p.48–51

4.10 方差、标准差与线性变换

连续方差定义为 Var(X) = E[(X − μ)2]，计算仍用捷径

Var(X) = E(X2) − [E(X)]2，   SD(X) = √Var(X)

对 f(x) = x/8（0 < x < 4）：E(X) = 8/3；

E(X2) = ∫04 x2(x/8)dx = [x4/32]04 = 256/32 = 8

故 Var(X) = 8 − (8/3)2 = 8/9，SD(X) = 2√2/3。

均匀分布的方差公式为

Var(X) = (b − a)2/12，   SD(X) = (b − a)/√12

推导先用 E(X2) = (a2 + ab + b2)/3，再减去 [(a+b)/2]2。例 X ~ Uniform(0, 10)：E = 5，Var = 100/12 ≈ 8.333，SD ≈ 2.887。

线性变换 Y = a + bX：E(Y) = a + bE(X)，Var(Y) = b2Var(X)，SD(Y) = |b|SD(X)。分钟换秒 Y = 60X：E(Y) = 300 秒，Var(Y) = 3600 × 100/12 = 30,000。

成本例：维修时间 X 的 E = 8/3、Var = 8/9，成本 C = 200 + 150X。则 E(C) = 200 + 150(8/3) = 600，Var(C) = 1502(8/9) = 20,000，SD(C) ≈ 141.42。固定成本 200 改变均值，不改变变异性。

易错

Var(a + bX) = b2Var(X)，不是 a + bVar(X)。常数项对离散程度没有贡献。

W4 p.52–59

4.11 分段密度与库存综合案例

许多连续分布分段定义。处理步骤：识别支撑集 → 检查非负 → 在正确区间积分 → 写 CDF 时对不同区域用不同表达式。若 PDF 只在 (a, b) 非零，则 F(x) = 0（x ≤ a）、∫axf(t)dt（a < x < b）、1（x ≥ b）。支撑集内部要积到 x，不是积到上限 b。

讲义需求模型：周需求 X（千盒）的密度 f(x) = k(x − 2)（2 < x < 4）。令 u = x − 2，则 1 = k∫02u du = 2k，k = 1/2。

于是 f(x) = (x − 2)/2。对 2 < x < 4，F(x) = ∫2x (t−2)/2 dt = (x−2)2/4。故 P(2.5 < X < 3.5) = F(3.5) − F(2.5) = 0.5625 − 0.0625 = 0.5。

均值：E(X) = ∫24 x(x−2)/2 dx = (1/2)∫24(x2 − 2x)dx = 10/3 ≈ 3.333 千盒。方差：E(X2) = 34/3，Var = 34/3 − (10/3)2 = 2/9，SD ≈ 0.471。

库存决策：若备货 3.6 千盒，缺货概率 P(X > 3.6) = 1 − F(3.6) = 1 − (1.6)2/4 = 1 − 0.64 = 0.36。若要 75% 服务水平，解 (q0.75 − 2)2/4 = 0.75，得 q0.75 = 2 + √3 ≈ 3.732 千盒。概率模型直接支撑了备货决策。

考点

分段密度的 CDF 必须分三段写；求区间概率用 F(b) − F(a) 前先确认两个端点都落在同一段公式内，否则要分别代入。

W4 p.63–71

4.12 常见错误与连续分布解题流程

讲义给出六类错误：把 f(x) 当成 P(X = x)；忘记检查总面积为 1；忘记在支撑集外补 F(x) = 0 或 1；把端点包含与否当成会影响概率；把 Var(X) 算成 E(X2) − E(X)；解释均值与标准差时漏掉单位。

应用题的通用流程：定义随机变量与单位 → 写清支撑集 → 检验或求出归一化常数 → 若需多次算概率就先建 CDF → 计算概率、期望、方差或分位数 → 回到原情境解释结果。

两个同支撑集的密度对比也值得记住：f1(x) = 1/4 与 f2(x) = x/8 都在 (0, 4) 上。前者均值 2，后者均值 8/3 ≈ 2.667。支撑集相同不代表概率、均值或方差相同；密度形状决定了质量往哪里集中。

连续变量的方差公式是 E(X2) − [E(X)]2，方括号不能丢。写成 E(X2) − E(X) 是最典型的计算错误。
