术语词典

Introduction to Programming in Java · 85 条

本学科 · 按章节顺序
中文 English 释义 章节
汇编语言 assembly language 由简单助记符指令组成、直接操作内存与寄存器的低级语言。 01
位 bit 一个二进制数位，取值 0 或 1，对应电路的通与断。 01
断点 breakpoint 让程序执行到该行时暂停的位置，用于调试。 01
字节 byte 8 位组成 1 字节，通常正好存放一个字符。 01
编译器 compiler 把源码转换成可执行字节码的工具。 01
转义字符 escape character 反斜杠加字符组成的序列，用来表示换行、制表或引号。 01
高级语言 high-level language 语法接近英语、便于人读写的语言，如 Java 与 C#。 01
集成开发环境 Integrated Development Environment 集编辑、构建、运行与调试于一体的开发工具。 01
Java 虚拟机 Java Virtual Machine 运行在真实机器内的虚拟 PC，把 Java 指令翻译成本机指令。 01
访问修饰符 access modifier 定义代码作用域、决定其他类能否访问的修饰符。 02
强制类型转换 casting 在值前用圆括号写出目标类型，把值从一种类型转成另一种。 02
数据类型 data type 说明数据是整数、小数、字符还是真假值，决定计算机如何处理。 02
浮点数 floating point number 带小数部分的数，Java 用 float 或 double 表示。 02
不可变 immutable 对象创建后内容不能修改，例如 String。 02
关键字 keyword Java 中有特定含义且区分大小写的保留词，如 public、class。 02
溢出 overflow 存入超过最大值的数，计算结果跳回最小值。 02
基本类型 primitive type Java 八种最基础的数据类型，它们不是对象。 02
变量 variable 具名的内存位置，用来存放可以改变的值。 02
包装类 wrapper class 为每种基本类型提供的对应类，如 int 对应 Integer。 02
数组 array 存放一组同类型值、创建后长度固定的容器。 03
break break 立即结束当前这一层循环，跳到循环之后执行。 03
continue continue 跳过本次迭代剩余语句，直接进入下一次迭代。 03
do-while 循环 do-while loop 先执行循环体再判断条件，因此循环体至少执行一次。 03
增强 for 循环 enhanced for loop 不使用下标、逐个取出元素值的遍历写法。 03
索引 index 数组中元素的位置编号，从 0 开始，最大为 length − 1。 03
嵌套循环 nested loop 一个循环体内再写一个循环，外层走行、内层走列。 03
二维数组 two-dimensional array 数组的数组，用行与列两个下标访问元素。 03
while 循环 while loop 每次迭代前先判断条件，条件一开始为假则不执行循环体。 03
装箱 boxing 把基本类型值转换成对应的包装类对象。 04
码元 code unit UTF-16 中一个 16 位单元，一个 char 正好存一个码元。 04
不可变性 immutability 对象创建后内容不变，任何修改操作都返回新对象。 04
方法 method 类中具名、可复用的代码块，被调用时执行。 04
方法签名 method signature 方法名加有序参数类型，用来区分重载。 04
重载 overloading 同一个类中方法名相同、参数列表不同的多个方法。 04
引用 reference 变量中保存的、指向堆上对象的内存地址。 04
字符串字面量 String literal 双引号包住的字符序列，其值不能改变，是表达式而非变量。 04
字符串池 string pool 相同字面量共享同一个 String 对象的机制。 04
代理对 surrogate pair 用高低两个码元表示 U+FFFF 以上字符的组合。 04
类 class 创建对象的模板，定义对象有哪些属性与行为。 05
构造方法 constructor 与类同名、无返回类型、在 new 时运行并为字段赋初值的方法。 05
控制类 controller class 含 main、负责创建并驱动数据对象的类。 05
封装 encapsulation 隐藏字段与内部实现，只通过 public 方法访问。 05
getter getter 返回 private 字段值的 public 方法。 05
堆 heap 存放对象、按需动态分配与释放的内存区域。 05
实例变量 instance variable 每个对象各自一份的字段，保存该对象的状态。 05
对象 object 把相关的数据（状态）与处理（行为）封装在一起的实体。 05
栈 stack 存放方法调用顺序与局部变量（含基本类型值）的内存区域。 05
向下转型 downcasting 把父类引用显式强制转换成子类类型。 06
final final 修饰字段时表示初始化后不能再修改，改动会编译报错。 06
继承 inheritance 子类获得父类实例变量与实例方法的机制，用于代码复用。 06
重写 overriding 子类用相同的方法名与参数列表重新实现父类方法。 06
多态 polymorphism 父类引用指向子类对象时，调用被重写的方法执行子类版本。 06
子类 subclass 通过 extends 继承另一个类的类。 06
super super 子类构造器中调用父类构造器的关键字，必须是第一条语句。 06
父类 superclass 被其他类继承的类，提供共享的字段与方法。 06
向上转型 upcasting 把子类引用赋给父类变量，编译器隐式完成。 06
checked 异常 checked exception 继承 Exception 且非 RuntimeException，编译器强制捕获或声明。 07
异常 exception 表示异常情况并打断正常指令流的对象。 07
异常链 exception chaining 包装新异常时把原异常作为 cause 传入，保留故障现场。 07
finally finally 无论正常结束还是异常传播都会执行的清理块。 07
栈轨迹 stack trace 记录导致失败的调用链，最上面一帧是真正的抛出点。 07
throw throw 在运行期创建并抛出异常对象的语句。 07
Throwable Throwable 所有可抛出对象的根类，下分 Error 与 Exception。 07
throws throws 方法签名中声明该方法可能抛出哪些异常的子句。 07
try-with-resources try-with-resources 在 try 括号中声明资源并自动关闭的语法。 07
unchecked 异常 unchecked exception 继承 RuntimeException，属程序缺陷，编译器不作要求。 07
AutoCloseable AutoCloseable 使对象能用于 try-with-resources 并被自动关闭的接口。 08
缓冲 buffering 一次读写一大块数据，以减少系统调用次数的机制。 08
字节流 byte stream 以 8 位字节为单位读写的流，适用于二进制数据。 08
字符流 character stream 以 Unicode 字符为单位读写的流，适用于文本。 08
装饰器 decorator 包装已有流以追加缓冲等能力、保持接口不变的写法。 08
乱码 mojibake 用错误字符集解码文本时出现的错误字符。 08
序列化 serialization 把对象字段转换成字节，以便保存或传输。 08
StandardOpenOption StandardOpenOption 控制文件打开方式（创建、追加、清空）的枚举。 08
流 stream 一段有序的数据序列，是 Java 读写外界的统一模型。 08
ArrayList ArrayList java.util 中可自动扩容的有序列表，用 add/get/set/remove/size 等方法操作。 09
泛型 generics 用类型参数（如 ArrayList<Student>）让容器在编译期检查元素类型。 09
输入校验 input validation 在继续处理前检查用户输入是否满足类型、范围与业务规则。 09
菜单循环 menu loop 反复显示选项、读取选择并调用相应方法，直到用户选择退出。 09
基准情形 base case 递归中不再调用自身、直接返回结果的条件。 10
调用栈 call stack 保存每次方法调用的参数、局部变量与返回位置的后进先出结构。 10
竞争条件 race condition 多个线程未同步地读写共享数据，结果依赖调度顺序的错误。 10
递归 recursion 方法调用自身来解决规模更小的同类问题，必须有可达的基准情形。 10
子序列 subsequence 从原序列中按原顺序保留或跳过若干字符所形成的序列。 10
线程 thread 程序内部独立执行的指令流；Java 用 Thread 或 Runnable 创建。 10
