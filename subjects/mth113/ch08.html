正态应用与指数分布

Normal Applications & Exponential Distribution

本讲把正态计算从“给区间求概率”反过来变成“给概率求临界值”，用于分位数、规格限与服务目标；随后引入指数分布描述等待时间，掌握其 CDF、生存函数、均值与无记忆性。

本章要点

  • 正态分位数：xp = μ + zpσ，其中 zp = Φ−1(p)。
  • 常用临界值：z0.90 = 1.282，z0.95 = 1.645，z0.975 = 1.960，z0.99 = 2.326。
  • 上尾问题先转成下尾：P(X > c) = 0.01 等价于 P(X < c) = 0.99。
  • 中间 95% 区间为 μ ± 1.96σ；减小 σ 或把 μ 移到规格中心都能提高合格率。
  • 指数分布 f(x) = λe−λx（x ≥ 0），F(x) = 1 − e−λx，S(x) = e−λx。
  • E(X) = 1/λ，Var(X) = 1/λ2；注意区分率参数 λ 与均值参数 β = 1/λ。
  • 指数分布无记忆：P(X > s+t | X > s) = P(X > t)，风险率恒为 λ。
  • Poisson 过程的事件计数与等待时间互为两面：N(t) ~ Pois(λt)，首次事件等待时间 ~ Exp(λ)。

8.1 从概率到分位数：反标准化

第 7 周做的是“已知 x 求概率”：P(X < x) = Φ((x−μ)/σ)。本讲反过来：“已知概率 p 求临界值 c”。若 X ~ N(μ, σ2) 且 P(X < c) = p，分两步：

  1. 找 zp 使 Φ(zp) = p。
  2. 反标准化：c = μ + zpσ。

因此第 p 分位数为

xp = μ + zpσ，   zp = Φ−1(p)

常用临界值要记：z0.90 = 1.282，z0.95 = 1.645，z0.975 = 1.960，z0.99 = 2.326。下尾的 z0.10 = −1.282，z0.05 = −1.645，由对称性得到。

上尾问题先转下尾。若要求 P(X > c) = 0.01，则 P(X < c) = 0.99，用 z0.99 = 2.326。若直接对 0.01 查表而忘记取补，会得到负的临界值，位置完全错误。

考点

“只有 1% 超过”是上尾 0.01，对应下尾 0.99；临界值是 μ + 2.326σ，不是 μ − 2.326σ。

W8 p.5–7

8.2 正态分位数的典型应用

例 1（上尾）：注册时间 X ~ N(12, 22) 分钟，求只有 1% 学生超过的时间。P(X > c) = 0.01 ⇒ P(X < c) = 0.99，z0.99 = 2.326，c = 12 + 2.326(2) = 16.652 分钟。

例 2（下尾）：考试成绩 X ~ N(70, 122)，求最低 10% 的临界值。z0.10 = −1.282，c = 70 + (−1.282)(12) = 54.616。约 10% 的成绩低于 54.6。

例 3（中间区间）：X ~ N(μ, σ2) 的中间 95% 为 μ ± 1.96σ。若 X ~ N(500, 202)，则 500 ± 1.96(20) = 500 ± 39.2，即约 (460.8, 539.2)。

例 4（规格限）：零件长度 X ~ N(50, 0.32) mm，合格范围 49.5 < X < 50.4。zL = (49.5−50)/0.3 = −1.667，zU = (50.4−50)/0.3 = 1.333。P = Φ(1.333) − Φ(−1.667) ≈ 0.9088 − 0.0478 = 0.8610。约 86.1% 合格。

例 5（等级线）：成绩 X ~ N(72, 92)，前 15% 得 A。要求 P(X > c) = 0.15，即 P(X < c) = 0.85，z0.85 ≈ 1.036，c = 72 + 1.036(9) ≈ 81.324。

易错

分位数公式里的 zp 要和累积方向一致。上尾 5% 对应 z0.95 = 1.645，不是 z0.05。先把“超过/低于/中间”画成尾部，再选 z。

W8 p.8–11、56

8.3 规格限与过程改进

制造场景中，规格限给出合格区间，正态模型把合格率转成两个 z 之间的面积。若目标 50 mm、合格范围 49.5 到 50.5，提高合格率有两条路：

  1. 把过程中心移到目标：让 μ 更接近 50。
  2. 减小变异：降低 σ。

数学效果不同。移动 μ 使两个标准化限同时向同一方向平移，可能改善一侧却恶化另一侧；减小 σ 使两个限离 0 更远，中心面积增大，通常同时降低两侧超规概率。

讲义强调“模型判断”：正态曲线是模型，不是保证。若过程有偏移、刀具磨损或混批，单峰正态可能不够；此时应先分层或改用其他模型，而不是硬套公式。合格率计算只在该模型成立的条件下有效。

辨析

“中心对准”与“降低变异”是两种能力：前者是准确性（accuracy），后者是精密度（precision）。合格率同时受两者影响。

W8 p.11–12

8.4 正态模型是否合适：图与判断

正态模型最适合“受许多小的独立变异源影响的连续测量”。不太合适的情形：数据强偏态；变量不能为负且大量聚集在 0 附近；存在多个峰；尾部远厚于正态。

图形检查三件套：直方图是否大致对称单峰；箱线图是否有强偏或大量异常值；正态概率图（normal probability plot）上的点是否大致成直线。小样本即使来自正态总体也可能看起来不规则，因此要结合样本量与情境判断，不能只看一张图就下结论。

讲义还给出模型选择的练习：班车每 12 分钟一班、乘客随机到达，等车时间用均匀；机器生产的螺栓直径用正态；安静时段下一单在线订单的等待时间用指数；软件生成的 0 到 1 随机数用均匀。选择依据是“支撑集 + 形状 + 生成机制”，不是“哪个公式背得熟”。

考点

判断正态性要看图形与情境，不能只看均值方差。若变量有硬下界 0 且右偏，指数或对数正态通常比正态更合理。

W8 p.14–16、32

8.5 指数分布：等待时间的密度

指数分布exponential distribution常用于建模直到某事件发生的等待时间：下一位顾客到达的时间、恒定失效率下元件的寿命、下一次服务来电的时间、Poisson 过程中事件之间的间隔。Poisson 计数“区间内有多少事件”，指数建模“到下一次事件要等多久”。

使用率参数 λ > 0，密度为

f(x) = λe−λx，x ≥ 0；  x < 0 时为 0

记 X ~ Exponential(λ)。密度在 0 处最高，随等待时间增加而指数衰减，因此分布右偏、长尾向右。

合法性检验：∫0∞λe−λxdx = [−e−λx]0∞ = 0 − (−1) = 1，且 f(x) ≥ 0，所以是合法 PDF。

易错

指数分布的支撑集是 [0, ∞)，不是整条实轴。写 PDF 时必须在 x < 0 处补 0，否则积分不为 1。

W8 p.17–19

8.6 指数 CDF 与生存函数

对 x ≥ 0，

F(x) = ∫0xλe−λtdt = 1 − e−λx

完整写法：F(x) = 0（x < 0），1 − e−λx（x ≥ 0）。

生存函数特别简洁：

S(x) = P(X > x) = 1 − F(x) = e−λx

右尾计算因此只需一次指数运算。例 λ = 0.2，P(X > 10) = e−0.2(10) = e−2 ≈ 0.1353。

区间概率也有简洁形式：P(a < X < b) = (1−e−λb) − (1−e−λa) = e−λa − e−λb。例 λ = 0.5，P(2 < X < 6) = e−1 − e−3 ≈ 0.3679 − 0.0498 = 0.3181。

指数 CDF 的“1 减指数”结构使它与几何分布形成离散/连续的对应：几何用 (1−p)k，指数用 e−λx，两者都有无记忆性。

考点

“超过 t”直接用 e−λt；“小于 t”用 1 − e−λt；“介于 a 与 b”用 e−λa − e−λb。三个公式都由同一条 CDF 推出，不要分别死记。

W8 p.20–21、26

8.7 指数均值、方差与两种参数化

若 X ~ Exponential(λ)，则

E(X) = 1/λ，  Var(X) = 1/λ2，  SD(X) = 1/λ

平均等待时间是 1/λ；事件率越大，平均等待越短。注意均值与标准差相等，这是指数分布的特征。

有些书用均值/尺度参数scale parameter β = 1/λ：f(x) = (1/β)e−x/β，此时 E(X) = β，Var(X) = β2。读题时先确认参数是率还是均值；把 λ 与 β 混用会使答案整体取倒数。

顾客到达例：平均每小时 3 人，X 为到下一位顾客的小时数，X ~ Exponential(3)。P(X > 1/3) = e−3(1/3) = e−1 ≈ 0.3679；E(X) = 1/3 小时 = 20 分钟。

元件寿命例：X ~ Exponential(0.25) 年。E(X) = 4 年；P(X > 5) = e−1.25 ≈ 0.2865；P(X < 2) = 1 − e−0.5 ≈ 0.3935。

易错

λ 是率、1/λ 是均值。若题目给“平均等待 15 分钟”，则每分钟的 λ = 1/15；若给“每小时 4 次”，则 λ = 4（以小时计）。

W8 p.22–25

8.8 指数分位数、无记忆性与风险率

解 F(xp) = p：1 − e−λxp = p ⇒ e−λxp = 1−p，取对数得

xp = −ln(1 − p) / λ

中位数为 ln(2)/λ。例 λ = 0.4，中位数 = ln2/0.4 ≈ 1.733。

无记忆性memoryless property：

P(X > s+t | X > s) = e−λ(s+t)/e−λs = e−λt = P(X > t)

已经存活 s 之后，剩余寿命的分布与一开始相同。例 λ = 0.08 月−1，已知已用 12 个月，求再用至少 6 个月：P(X > 18 | X > 12) = P(X > 6) = e−0.08(6) = e−0.48 ≈ 0.6188。

无记忆性何时合理：事件率近似恒定。电子元件在有效寿命期内的失效、稳定队列中的随机到达、罕见独立事件之间的时间，都可以近似。人体衰老、机械磨损、季节性需求、学习效应会违反恒定率，指数模型不合适。

风险率hazard rate是“已存活到 x 的条件下瞬时失效率”。指数分布的 h(x) = λ 恒定，这从另一角度解释了无记忆：失败率不随年龄上升或下降。

考点

无记忆性写成 P(X > s+t | X > s) = P(X > t)，条件是“已经活了 s”。计算时直接把 s 消掉，不要重新算总概率。

W8 p.27–29、44、46

8.9 与 Poisson 过程的联系

若事件按速率 λ（每单位时间）的 Poisson 过程发生，则：

  • 时间 t 内的事件数 N(t) ~ Pois(λt)；
  • 到第一次事件的等待时间 X ~ Exponential(λ)。

两者由同一个等式连接：

P(X > t) = P(N(t) = 0) = e−λt

“等待超过 t”意味着“t 内一个事件都没有”。计数与等待是同一过程的两个视角：问“一小时内有几次”用 Poisson，问“下一次要等多久”用指数。

例：服务台每小时 4 次请求。未来 10 分钟（1/6 小时）内至少一次请求的概率，可以用 Poisson λ = 4/6 = 0.6667，P(N ≥ 1) = 1 − e−0.6667 ≈ 0.4866；也可以直接用指数 P(X < 1/6) = 1 − e−4/6 ≈ 0.4866。两条路答案相同，因为它们描述同一件事。

辨析

Poisson 的 λ 是“每单位时间的事件数”，指数的 λ 是“事件发生的率”。数值相同但角色不同：前者进入计数均值，后者进入等待时间的倒数。

W8 p.30

8.10 均匀、正态与指数的比较

三种连续模型的适用边界
维度均匀正态指数
支撑集有限区间整条实轴[0, ∞)
形状平坦对称钟形右偏衰减
典型用途等可能取值围绕均值的测量等待时间/寿命
参数a, bμ, σλ
均值(a+b)/2μ1/λ

选择模型看三件事：支撑集是否匹配、形状是否匹配、生成机制是否匹配。正态分布支撑整条实轴，若用它建模等待时间，会给负时间赋予正概率；虽然 μ 远大于 σ 时这个概率很小，但模型假设仍然不对。指数分布支撑 [0, ∞)，适合恒定率的等待；若等待时间有固定上限或明显非单调风险，指数也不合适。

模型选择练习：班车每 12 分钟一班、随机到达 → 均匀；机器生产螺栓直径 → 正态；安静时段下一单在线订单的等待 → 指数；软件生成 0 到 1 随机数 → 均匀。

考点

“等待时间”优先想指数；“围绕目标值的测量”优先想正态；“等长区间等可能”想均匀。三者不能仅凭“看起来像钟形”互换。

W8 p.31–32、52

8.11 综合案例与常见错误

服务目标例：帮助台请求率 λ = 6 次/小时。管理层要求“等待超过 t 分钟的概率至多 5%”：

P(X > t/60) = e−6t/60 ≤ 0.05  ⇒  −6t/60 ≤ ln(0.05)  ⇒  t ≥ −10 ln(0.05) ≈ 29.96

约 30 分钟即为 95 百分位等待时间。

保修例：元件寿命 X ~ Exponential(0.08)（月）。保修 12 个月，索赔概率 P(X < 12) = 1 − e−0.96 ≈ 0.6171。若售出 1,000 件，期望索赔约 617.1 件。模型批评：若早期缺陷或磨损重要，恒定失效率过于简单。

讲义列出五类错误：混淆 σ2 与 σ；不标准化就用 Φ(z)；忘记 P(X > t) = e−λt；混淆率 λ 与均值 1/λ；把无记忆性套到非指数寿命模型。

解题清单：识别随机变量与单位 → 选模型并写参数 → 用记号写出所求概率或分位数 → 画密度并阴影区域 → 用 CDF、生存函数、标准化或反公式 → 回到情境解释数值。

易错

“均值 15 分钟”要转成率 λ = 1/15 每分钟，或 4 每小时；直接把 15 代入 e−15t 会把率和均值弄反。

W8 p.33、53–55、59

8.12 离散与连续等待时间的对照

几何分布与指数分布处理同一类直觉问题——“还要等多久才成功/才发生”，但一个数试验次数，一个数连续时间。把两者并排看，能避免把 PMF 与密度、把 (1−p)k 与 e−λt 混用。

几何分布与指数分布的对应关系
维度几何（离散）指数（连续）
随机变量直到第一次成功的试验次数直到下一次事件的等待时间
取值1, 2, 3, …[0, ∞)
概率函数P(X=x)=(1−p)x−1pf(x)=λe−λx
CDF1−(1−p)k1−e−λx
均值1/p1/λ
无记忆性已失败 s 次后剩余等待不变已存活 s 后剩余寿命分布不变

对照的关键是“参数角色”：几何的 p 是每次试验的成功概率，指数的 λ 是单位时间的事件率。两者都取倒数得到平均等待，但 p 无量纲，λ 有“每单位时间”的量纲，所以 1/λ 才带时间单位。

无记忆性的表述也要随情形改写：几何说“已经失败 s 次，接下来再等 t 次的分布与一开始相同”；指数说“已经存活 s 小时，接下来再存活 t 小时的概率与从 0 开始相同”。两者成立的前提都是恒定成功率/恒定风险率，一旦磨损或学习效应使率变化，无记忆性就不再适用。

辨析

几何的“第 x 次成功”是单点概率，指数在单点的概率为 0；问指数“第 x 小时发生”没有意义，只能问区间。这是离散与连续最根本的差别。
