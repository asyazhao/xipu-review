Poisson 与几何分布

本讲补齐核心离散模型：Poisson 描述固定时间、面积或体积内的事件计数，几何分布描述直到第一次成功所需的试验次数；最后用一张模型选择表把 Bernoulli、二项、Poisson 与几何区分开。

本章要点

  • Poisson 模型适用于固定区间内随机、独立、平均速率恒定的事件计数，计数没有固定上限。
  • Poisson PMF：P(X=x) = e−λλx/x!，x = 0,1,2,…；E(X) = Var(X) = λ。
  • 率要随区间缩放：λ = rt；时间单位必须先统一。
  • n 大、p 小时可用 Poisson(np) 近似二项；p 不小时近似很差。
  • 几何分布计数“直到第一次成功的试验次数”，支撑集为 1,2,3,…；本课程约定包含成功那次。
  • 几何 PMF P(X=x) = (1−p)x−1p，CDF 1−(1−p)k，E(X) = 1/p。
  • 几何分布无记忆：P(X > s+t | X > s) = P(X > t)。
  • 选模型先问“随机变量数什么、取值范围是什么”，再检查独立性、恒定率等假设。

6.1 四种离散模型的分工

第 5 周用 Bernoulli 描述一次成功—失败试验，用二项描述固定 n 次试验中的成功数。本讲再加入两类：Poisson 描述固定区间内的事件数，几何描述直到第一次成功所需的试验次数。

四种特殊离散模型的适用问题
模型最适合主要参数
Bernoulli一次成功—失败试验p
二项固定 n 次独立试验中的成功数n, p
Poisson固定时间/空间/面积区间内的事件数λ
几何直到第一次成功的试验次数p

讲义用一组动机例子建立直觉：服务中心下一小时到达的来电数、每平方米材料上的小缺陷数、网站每天的报错数，这些是“固定区间内有多少事件”，用 Poisson；询问多少位顾客才出现第一次购买、尝试多少次才首次登录成功，这些是“直到第一次成功要多少次”，用几何。

同一个现实过程可以对应不同的随机变量。顾客按 Poisson 过程到达，若只问“一小时内有多少人购买”，计数用 Poisson；若问“第几位顾客才是第一位购买者”，等待用几何。先定义随机变量，再选分布。

考点

区分“固定区间内的计数”（Poisson）与“固定次数中的成功数”（二项）。前者的上限不固定，后者的上限是 n。

6.2 Poisson 模型与四条假设

Poisson 分布Poisson distribution建模固定区间内以平均速率随机发生的事件计数。讲义例子：每小时来电数、每页打字错误数、每月故障数、每秒粒子发射数、每 10 分钟到达顾客数。Poisson 是计数模型，计数没有固定上限。

模型合理的四条假设：

  1. 事件相互独立发生。
  2. 平均速率在区间内恒定。
  3. 在极小的子区间内发生两个或更多事件的概率极小。
  4. 随机变量计数的是固定区间内的事件数。

若事件强烈聚集，或速率随时间变化（例如高峰与低谷），简单 Poisson 模型可能很差。讲义把这称为“模型检查”：公式好用，但假设不成立时结论不可信。

若 X 服从参数 λ > 0 的 Poisson 分布Poisson distribution，记 X ~ Pois(λ)，PMF 为

P(X = x) = e−λ λx / x!，  x = 0, 1, 2, …

λ 是所研究区间内事件数的期望。注意 λ 与区间绑定：同一过程在 1 小时与 20 分钟下的 λ 不同。

易错

λ 不是“速率”本身，而是“速率 × 区间长度”。题目给 6 次/小时，问 20 分钟时必须先换算成 λ = 2，不能直接用 6。

W6 p.8–10

6.3 Poisson PMF 的合法性

用指数级数证明 PMF 总和为 1：

eλ = Σx=0∞ λx/x!

因此

Σx=0∞ e−λλx/x! = e−λ Σ λx/x! = e−λeλ = 1

且 e−λ > 0、λx > 0、x! > 0，所以每项非负。Poisson 公式在所有非负整数计数上构成合法 PMF。

这个证明也解释了 e−λ 的角色：它是归一化因子，保证概率总质量为 1。P(X=0) = e−λ，这是最常用的单点概率，也是递推表的起点。

辨析

Poisson 的 x 从 0 开始，几何的 x 从 1 开始。两者的支撑集不同，写 PMF 前先确认“0 是否可能”。

W6 p.11

6.4 均值、方差与过离散诊断

若 X ~ Pois(λ)，则

E(X) = λ，   Var(X) = λ，   SD(X) = √λ

均值与方差相等是 Poisson 的重要特征。讲义把它当作诊断工具：若实际数据的方差远大于均值，可能存在过离散overdispersion，简单 Poisson 模型会低估尾部概率。原因可能是速率变化、事件聚集或区间之间不可比。

例：某网站平均每天 4 次报错，X ~ Pois(4)。则 E(X) = Var(X) = 4，SD = 2。若实际观测的日方差是 20，就说明“每天速率恒定、事件独立”的假设值得怀疑。

Poisson 的方差随 λ 增大而增大，标准差随 √λ 增大。这与二项的 np(1−p) 不同：Poisson 只有一个参数，均值和方差被绑在一起。

考点

E(X) = Var(X) = λ 必须同时记住。若题目给出均值与方差不等，就不能直接套 Poisson，除非说明是样本波动。

W6 p.12、46

6.5 率的缩放：λ = rt

若事件平均每个单位时间发生 r 次，区间长度为 t，则区间内的 Poisson 参数为

λ = r t

例：服务台平均每小时 6 通来电。1 小时 λ = 6；20 分钟 = 1/3 小时，λ = 6(1/3) = 2；2 小时 λ = 12。速率与区间必须换算到同一单位，否则 λ 没有意义。

同样的缩放适用于面积、长度与体积：织物每平方米 0.8 个瑕疵，5 平方米一卷的 λ = 0.8 × 5 = 4；某路段每公里 2 个坑洞，10 公里的 λ = 20。

讲义的服务台例：来电率 6 次/小时，问未来 20 分钟无来电的概率。λ = 2，P(X=0) = e−220/0! = e−2 ≈ 0.1353，约 13.53%。

缩放的反向问题也常考：已知某区间内平均 2 次事件，问速率是多少。此时 r = λ/t。若 20 分钟平均 2 次，则每小时 6 次。

易错

时间单位不统一是 Poisson 题最常见的失分点。题目给“每小时”，问“每 15 分钟”时必须乘 0.25；给“每天”，问“每周”时必须乘 7。

W6 p.13–14

6.6 Poisson CDF、尾部与边界

Poisson 的 CDF 是逐项求和：F(k) = P(X ≤ k) = Σx=0k e−λλx/x!。对 X ~ Pois(2)：

P(X ≤ 2) = e−2(1 + 2 + 22/2) = 5e−2 ≈ 0.6767

因此 P(X ≥ 3) = 1 − 0.6767 = 0.3233。注意补集退到 2，而不是 3。

网站报错例：X ~ Pois(4)。P(X=0) = e−4 ≈ 0.0183；P(X ≤ 2) = e−4(1 + 4 + 16/2) = 13e−4 ≈ 0.2381；P(X ≥ 3) = 0.7619。

织物瑕疵例：每平方米 0.8 个瑕疵，5 平方米卷材 λ = 4，P(X=5) = e−445/5! ≈ 0.1563。Poisson 率可随时间、面积、长度或体积缩放，关键是区间与率匹配。

形状上，λ 增大使 Poisson 分布右移、偏度减小、逐渐接近钟形；λ 较小时右偏明显，0 的概率不可忽略。

考点

P(X ≥ 3) = 1 − P(X ≤ 2)。Poisson 的补集边界与二项相同：上尾要退一位。计算 P(X≤k) 时把 e−λ 提出求和，可减少重复运算。

W6 p.15–19

6.7 Poisson 近似二项

当 X ~ Bin(n, p) 且 n 大、p 小时，可用

X ≈ Pois(λ = np)

这适用于“很多次机会中的罕见事件”：大量产品中的少量缺陷、大量患者中的罕见不良事件、大量交易中的少量错误。

例：X ~ Bin(500, 0.004)，λ = 500(0.004) = 2。用 Y ~ Pois(2) 近似：P(X ≤ 1) ≈ P(Y ≤ 1) = e−2(1 + 2) ≈ 0.4060。精确二项值约 0.4055，近似非常接近。

不适用的情形：p 不小、n 不大、事件不独立、存在会起作用的固定上限、事件率在区间内变化。讲义反例：用 Poisson 近似 Bin(10, 0.5) 很差，因为成功并不罕见。

近似好用的原因可以这样看：二项 PMF 在 n 大、p 小时可写成 C(n,x)px(1−p)n−x，其中 (n)xpx ≈ λx，(1−p)n ≈ e−λ。讲义不要求推导，只要求会判断适用性。

易错

近似的前提是“罕见事件”。p = 0.5 时即使 n 很大，Poisson 也不是好近似；此时二项分布接近对称，而 Poisson 仍右偏。

W6 p.20–22

6.8 Poisson 递推、可加性与拆分

相邻概率满足递推：

P(X=x+1) / P(X=x) = λ/(x+1)

从 P(X=0) = e−λ 出发即可逐项建表。例 X ~ Pois(3)：0.0498、0.1494、0.2240、0.2240、0.1680、0.1008、0.0504。对 λ = 3，最可能的计数在 2 与 3 附近。

可加性：若 X ~ Pois(λ1)、Y ~ Pois(λ2) 且独立，则 X + Y ~ Pois(λ1 + λ2)。产品 A 每小时 2 通来电、产品 B 每小时 5 通，合计每小时 7 通。

拆分：若 N ~ Pois(λ)，每个事件独立地以概率 p 属于类型 A，则 NA ~ Pois(λp)，NB ~ Pois(λ(1−p))。可用于按类别分来电、按类型分错误、按严重程度分缺陷。

从数据估率：在 T 个暴露单位内观测到 x 次事件，则 r̂ = x/T；未来长度 t 的区间用 λ̂ = r̂t。例：8 小时 24 通来电，r̂ = 3 次/小时，30 分钟的 λ̂ = 1.5。

考点

独立 Poisson 相加，参数相加；按概率拆分，参数按比例拆分。两类操作都不要把 λ 直接相加而忽略比例。

W6 p.41–45

6.9 几何分布：定义、条件与 PMF

几何分布geometric distribution建模直到第一次成功所需的试验次数。例：直到第一次成交的销售电话数、直到登录成功的尝试次数、直到第一个次品的检查件数、直到第一套满意公寓的看房次数。固定次数问成功数用二项；直到第一次成功用几何。

几何模型的条件：试验独立；每次只有成功/失败两种结果；成功概率 p 恒定；X 计数直到第一次成功的试验次数，包含成功那次。

约定警告：有些书或软件把几何定义为“第一次成功之前的失败次数”。本课程采用“直到第一次成功的试验次数”，支撑集为 1, 2, 3, …。两种约定相差 1，用软件时必须核对。

若 X = x，则前 x−1 次都失败、第 x 次成功：FF…FS。由独立性，

P(X = x) = (1 − p)x−1 p，  x = 1, 2, 3, …

令 q = 1 − p，则总和为 pΣj=0∞qj = p/(1−q) = 1。几何 PMF 合法。

易错

本课程几何的 x 从 1 开始。若写成 x = 0,1,2,… 或把指数写成 x，整道题的数值会整体错位。

W6 p.25–28

6.10 几何 CDF、均值与方差

要算 P(X ≤ k)，先看补集“前 k 次全失败”：P(X > k) = (1−p)k。因此

F(k) = P(X ≤ k) = 1 − (1 − p)k，  k = 1, 2, …

均值和方差为

E(X) = 1/p，   Var(X) = (1 − p)/p2，   SD(X) = √(1−p)/p

成功越罕见，期望等待越长。例：销售员每次独立电话成交概率 p = 0.20，X ~ Geom(0.20)。P(X=4) = 0.83(0.2) = 0.1024；E(X) = 5 通电话。

累积与尾部：P(X ≤ 4) = 1 − 0.84 = 0.5904；P(X > 10) = 0.810 ≈ 0.1074。前者是“前 4 通内成交”的概率，后者是“需要超过 10 通”的概率。

公寓例：10% 的公寓可接受，每周看一套，X ~ Geom(0.10)。E(X) = 10 周；P(X ≤ 2) = 1 − 0.92 = 0.19；P(X > 17) = 0.917 ≈ 0.1668。

考点

几何 CDF 用补集最快：P(X ≤ k) = 1 − (1−p)k。E(X) = 1/p 的直觉是“平均每 1/p 次出现一次成功”。

W6 p.29–32、35–36

6.11 无记忆性、分位数与模型选择

几何分布具有离散情形下的无记忆性memoryless property：

P(X > s+t | X > s) = P(X > t)

证明：左边 = (1−p)s+t/(1−p)s = (1−p)t = 右边。已经失败了 s 次之后，剩余等待时间的分布与一开始相同；过去的失败不改变未来的成功概率。

分位数：要使 P(X ≤ k) ≥ q，解 1 − (1−p)k ≥ q，得

k ≥ log(1 − q) / log(1 − p)

结果向上取整。例 p = 0.20，要 90% 把握成交：k ≥ log(0.10)/log(0.80) ≈ 10.32，故需 11 通电话。中位数：解 1 − 0.8m ≥ 0.5，m ≥ log(0.5)/log(0.8) ≈ 3.11，中位数为 4 通。

模型选择的提问顺序：是 0/1 单次结果吗（Bernoulli）？是固定 n 次中的成功数吗（二项）？是固定区间内的事件数吗（Poisson）？是直到第一次成功的次数吗（几何）？先定义随机变量，再选分布。

按问题模式选择离散模型
问题模式随机变量模型
一件事是否发生？0/1 结果Bernoulli
固定 n 次中成功几次？0 到 n 的计数二项
固定区间内发生几次？0 到 ∞ 的计数Poisson
直到第一次成功要几次？1 到 ∞ 的计数几何

易错

无记忆性只对几何（离散）与指数（连续）成立，不能套到二项或 Poisson 上。几何的“过去失败不影响未来”来自恒定 p 与独立性。

6.12 综合案例与常见错误

客服中心例：投诉以平均每小时 3 次的速率到达。30 分钟内 λ = 3(0.5) = 1.5，无投诉概率 e−1.5 ≈ 0.2231。一小时内 Y ~ Pois(3)，至少 3 次投诉 P(Y ≥ 3) = 1 − P(Y ≤ 2) = 1 − e−3(1 + 3 + 9/2) = 1 − 8.5e−3 ≈ 0.5768。若每件投诉独立地以 0.20 的概率升级，则 10 件投诉中的升级数 Z ~ Bin(10, 0.20)。同一个案例同时用了 Poisson 与二项，说明“先分清随机变量”比“背公式”更重要。

Poisson 与几何可以在同一过程中共存：顾客以每小时 12 人到达，每人以 0.25 的概率购买。一小时内购买者数 ~ Pois(12 × 0.25) = Pois(3)；直到第一位购买者所需的顾客数 ~ Geom(0.25)。前者是“钟表时间内的计数”，后者是“按顾客编号的等待”，问题不同，分布不同。

讲义汇总 Week 5–6 的常见错误：试验次数不固定却用二项；有固定上限 n 却用 Poisson；忘记把 Poisson 率缩放到正确区间；混淆 P(X=k) 与 P(X≤k)；混淆几何的“直到成功”与“成功前失败”；忽略独立与恒定概率假设。

考点

综合题先写“设 X = …，单位 …”，再写分布与参数。若同一题有两个随机变量，分别命名、分别说明分布，不要把一个的 λ 用到另一个上。
