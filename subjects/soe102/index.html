课程从位与字节、二进制换算、JVM 与第一个 Java 程序讲起，随后依次展开数据类型与运算符、数组与三种循环、字符串与静态方法、对象与封装、继承与多态，最后落到异常处理与流式 I/O。语法点以可运行的程序为落点：代码要在 IntelliJ IDEA 里写出、构建、运行，出错时用断点调试。

高频易错点

  1. 声明 ≠ 赋值 — int number1; 之后变量还没有值，直接参与运算会编译报错；整数相除会丢掉小数部分，要小数结果就得把参与运算的变量声明成 double。
  2. 强制类型转换是截断，不是四舍五入 — 把 double 强转成 int 只保留整数部分；溢出与下溢也不报错，而是静默地环绕到另一端。
  3. 数组索引的最大值是 length − 1 — 合法范围是 0 到 array.length - 1，length 是字段、不带括号；而且必须先校验再访问，越界一旦发生，写在后面的提示语句根本执行不到。
  4. substring(start, end) 的 end 不包含在内 — 取 5 个字符写 substring(0, 5) 而不是 substring(0, 4)；比较内容用 equals，== 比的是引用。
  5. 引用赋值复制的是地址 — p2 = p1 之后两个变量指向同一个对象，改一个另一个也看得见；基本类型赋值才复制值本身。
  6. super(...) 必须是子类构造器的第一条语句 — 放到后面会编译失败；重写要求方法名与参数列表都相同，只改返回类型或参数名不会产生新签名，也不构成重载。
  7. finally 里的 return 会覆盖 try 的返回值 — 它还会吞掉正在传播的异常；catch 必须从具体排到一般，父类写在前面是编译错误而不是运行错误。
  8. 三种“结束”不是同一个值 — 字节流与字符流的 read() 到末尾返回 −1，readLine() 返回 null；另外 write 默认覆盖文件，追加要显式给 APPEND。
