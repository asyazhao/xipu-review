学术不端 academic offence 使用生成式 AI 完成作业等违反学术诚信的行为。 01
连续评估 continuous assessment 占总评 50% 的平时成绩，含实验、测验与项目。 01
期末考试 final examination 占总评 50% 的课程考试。 01
生成式人工智能 generative AI 能生成代码或文本的 AI 工具，作业中严格禁止使用。 01
集成开发环境 integrated development environment 支持 C/C++ 开发的编辑器、编译器与调试器集合。 01
办公时间 office hours 教师每周固定的当面答疑时段。 01
补考 resit examination 不计平时成绩、按 100% 计的成绩补救考试。 01
规格说明 specification 描述程序必须满足的需求，是分析与测试的起点。 01
终端 terminal 与计算机交互的文本界面，又称 console 或命令提示符。 01
算法 algorithm 为解决特定问题而设的一系列指令或过程性步骤。 02
字节码 bytecode Java 编译产生的中间码，可视为 JVM 的机器语言。 02
计算等价性 computational equivalence 所有计算机在时间与内存充足时能计算相同的东西。 02
可执行文件 executable file 面向特定平台、可直接由处理器运行的指令集合。 02
输入—处理—输出模型 input-process-output model 把程序视为把输入经处理转为输出的黑箱。 02
链接器 linker 把多个目标文件与库合并成一个可执行文件的工具。 02
目标文件 object file 编译产生的中间文件，含机器码与符号表等元数据。 02
平台无关程序 platform independent program 几乎不需修改即可在多种平台运行的程序。 02
问题变换 problem transformation 把人类语言的问题经多层抽象变为机器可执行形式。 02
源文件 source file 存放程序文本的文件，如 helloworld.cpp。 02
算法精化 algorithm refinement 把粗略步骤细化为可计算的表达式。 03
分解 decomposition 把大问题划分为更小的子问题。 03
函数声明 function declaration 只给出返回类型、名字与参数类型的声明。 03
链接错误 link error 缺少库或库名错误，导致无法生成可执行文件。 03
问题分析 problem analysis 明确输入、输出、约束与所需的数据类型。 03
问题识别 problem identification 判断问题是什么、题面是否存在歧义。 03
过程抽象 procedural abstraction 先定函数接口、暂缓实现子问题。 03
程序开发过程 program development process 从问题识别到测试的五个阶段。 03
运行时错误 runtime error 能编译能链接但结果错误的实现错误。 03
语法错误 syntax error 违反语言规则、导致无法编译的错误。 03
赋值语句 assignment statement 把右侧表达式的值写入左侧变量。 04
常量 constant 声明时赋值、之后不可修改的永久值。 04
数据类型 data type 刻画数据本质的基本抽象，决定内存占用与运算规则。 04
头文件 header file 含库函数与变量声明的文件，由 #include 引入。 04
标识符 identifier 变量、常量、函数等对象的名字。 04
运算符优先级 operator precedence 决定表达式中各运算符的求值先后。 04
保留字 reserved word 语言中有特殊含义、不能用作标识符的词。 04
类型转换 type conversion 改变表达式类型的操作，又称 casting。 04
变量 variable 有名字、有类型、可存放一个值的存储单元。 04
断言 assertion 检查某条件应成立，不成立则中止程序。 05
布尔类型 bool 只有 true 与 false 两个值的类型。 05
控制流 control flow 描述执行如何从一条命令进行到下一条。 05
悬垂 else dangling else 嵌套 if 中归属不明、实际绑定最近 if 的 else。 05
流程图 flowchart 用方框表示动作与判断、用边表示控制流。 05
伪代码 pseudocode 用高层指令描述步骤、不含真实语法的算法写法。 05
关系运算符 relational operator 比较两个值的大小或相等，结果为真或假。 05
短路求值 short circuit evaluation 逻辑表达式的值一旦确定就停止求值。 05
开关语句 switch statement 按离散值在多条分支中选择执行的语句。 05
入口控制循环 entry controlled loop 先判断条件再执行循环体，可能一次也不执行。 06
出口控制循环 exit controlled loop 先执行循环体再判断条件，至少执行一次。 06
标志 flag 记录状态、用于控制循环是否继续的变量。 06
自增 increment 把变量加一；++k 先加后用，k++ 先用后加。 06
无限循环 infinite loop 条件永不成立而无法终止的循环。 06
循环 loop 重复执行一段语句的控制结构，又称迭代。 06
循环计数器 loop counter 记录循环已执行次数的变量。 06
嵌套循环 nested loop 循环体内再包含循环，内层需完整执行。 06
哨兵值 sentinel value 标记输入结束的特殊数据值。 06
快捷赋值 shortcut assignment 把运算与存回合并的 +=、-=、*= 等运算符。 06
数组 array 同一类型元素的线性集合，存于连续内存。 07
维数 dimension 数组能存放的元素个数。 07
元素 element 数组中的一个数据项，由下标定位。 07
下标错误 incorrect indexing 使用超出 0 到 n−1 范围的下标。 07
索引 index 方括号内的值，合法范围从 0 到 n−1。 07
初始化 initialization 在声明时用列表给数组元素赋初值。 07
行主序 row-major ordering 二维数组按行依次连续存放的顺序。 07
下标 subscript 用方括号给出元素位置的写法。 07
二维数组 two-dimensional array 本质是数组的数组，按行与列记元素。 07
二分查找 binary search 每次与中间元素比较并排除一半区间；只能用于有序数组。 08
冒泡排序 bubble sort 反复交换相邻的逆序元素，使较大元素逐步移到末尾。 08
分治 divide-and-conquer 把问题分成更小的同类子问题，分别求解后合并结果。 08
提前退出 early exit 条件满足时立即结束循环，省去多余的比较。 08
线性查找 linear search 从第一个元素开始逐个与目标比较，直到找到或遍历完。 08
选择排序 selection sort 反复把未排序部分的最大元素换到这段的末尾。 08
交换 swap 借助一个临时变量互换两个变量的值。 08
未排序部分 unsorted part 数组中尚未确定最终位置的区段，每轮结束缩小一格。 08
抽象 abstraction 忽略不必要的细节，把“做什么”与“怎么做”分开。 09
黑箱 black box 只暴露接口、隐藏实现细节的代码部件。 09
函数重载 function overloading 同名函数靠参数的类型与个数不同来区分。 09
函数原型 function prototype 声明返回类型、函数名与参数类型，不含函数体。 09
传引用 pass by reference 把实参的地址交给函数，形参改变会反映到调用者。 09
传值 pass by value 把实参的值复制给形参，形参改变不影响实参。 09
签名 signature 由参数的类型与个数决定的函数标识，用于区分重载。 09
自顶向下编程 top-down programming 把问题逐层拆成子问题，每个子问题用一个函数解决。 09
驱动程序 driver program 专门用来反复调用待测函数、观察输出的小程序。 10
全局声明 global declaration 写在所有函数体之外的声明，通常放在文件开头。 10
迭代 iteration 用循环重复执行同一段代码，而不是调用自己。 10
局部声明 local declaration 写在函数体内的声明，只在该函数内可访问。 10
递归 recursion 把任务分解成更小的同类子任务，由函数调用自己完成。 10
作用域 scope 一个声明有效的代码块范围，出了块名字就失效。 10
遮蔽 shadowing 内层同名声明挡住外层或全局的同名标识符。 10
终止条件 stopping condition 递归中不再调用自己、直接返回值的条件。 10
桩 stub 与原函数接口相同但实现不完整的占位函数。 10
ASCII American Standard Code for Information Interchange 用 7 位编码 128 个字符的字符编码标准。 11
C 风格字符串 C-style string 以 '\0' 结尾的字符数组，容量须事先给定。 11
字符类型 char 用来存放单个字符的数据类型，字面量用单引号。 11
控制字符 control character 编码 0–31 与 127 的不可打印字符，用于格式与控制。 11
分隔符 delimiter 标记读取结束的字符；get 保留它，getline 取走并丢弃。 11
空字符 null character 编码为 0 的 '\0'，标记 C 风格字符串的结尾。 11
溢出 overflow 数值超出类型可表示的范围，结果被截断成错误值。 11
子串 substring 从指定位置开始、指定长度的连续字符，用 substr 取。 11
空白字符 whitespace 空格、制表符与换行，cin >> 提取时默认跳过。 11
文件结束 end-of-file 输入流已无字符可读的状态，用 eof() 检测。 12
字段宽度 field width 一个输出项占用的字符列数，setw 只作用于下一个输出项。 12
文件 file 存放在二级存储上的永久数据集合，读取前必须先打开。 12
输入文件流 ifstream 从外部文件读取数据的流类型，用 >> 或 get 读。 12
操纵符 manipulator 修改流标志的辅助函数，如 setw、setprecision、setiosflags。 12
输出文件流 ofstream 向外部文件写入数据的流类型，用 << 或 put 写。 12
精度 precision 浮点输出保留的位数，用 setprecision 设置并持续生效。 12
流 stream 对所有输入输出的抽象：按时间逐步到达的数据元素序列。 12
取地址运算符 address-of operator 写作 &，返回变量所占内存单元的地址。 13
悬空指针 dangling pointer 仍指向已被 delete 释放的内存的指针，使用即非法。 13
解引用 dereference 写作 *，按指针保存的地址访问所指的对象。 13
动态分配 dynamic allocation 运行期用 new 从堆上取得内存，用 delete 归还。 13
堆 heap 程序中存放全局数据、并提供动态分配的空闲内存区。 13
内存泄漏 memory leak 分配的内存地址被覆盖丢失，程序再也无法释放它。 13
空指针 nullptr 表示不指向任何对象的特殊指针值，解引用它会出错。 13
指针 pointer 存放内存地址的变量，可通过该地址引用对应存储。 13
指针算术 pointer arithmetic 指针加减以所指类型的元素为单位，p+n 偏移 n 个元素。 13
栈 stack 存放活动函数局部数据的内存区，随调用逐层增长。 13
抽象数据类型 abstract data type (ADT) 用操作接口描述数据类型的模型，隐藏具体实现。 14
成员访问 member access 用点运算符 object.member 或箭头 p->member 访问结构体成员。 14
结构体 struct 把不同类型成员组合成一个新类型的 C/C++ 构造。 14
类型别名 typedef 用 typedef 为已有类型起一个新名字，简化声明。 14
联合体 union 多个成员共享同一块存储、同一时刻只能有效使用一个成员的类型。 14
头指针 head pointer 指向链表第一个节点的指针；空表时通常为 nullptr。 15
链表 linked list 节点用指针串联、元素不要求连续存储的线性数据结构。 15
合并链表 merge 把两个有序链表按顺序合并为一个有序链表。 15
节点 node 链表中存放数据与下一个节点地址的结构体。 15
有序插入 sorted insertion 在保持链表有序的前提下找到插入位置并连接新节点。 15
遍历 traversal 从 head 出发沿 next 指针依次访问每个节点。 15
