SCI101 面向科学各学科的入门学生，用 Python 与基础数学（线性代数、微积分、统计）搭建在科研中使用 AI/ML 的工具箱。课程按“数学 → 数据 → 监督/无监督 → 算法 → 聚类 → 评估 → 感知机与深度学习”的顺序展开，并明确声明自己不是机器学习课、计算科学课或算法课。

高频易错点

  1. “表示”与“模型”是两件事 — 同一份数据换一种表示（缩放、筛选、编码）就会改变模型效果；选模型不等于选表示。
  2. 逻辑回归是分类，不是回归 — 它输出 0–1 的概率，需再取阈值才变成类别；预测连续数值的才是线性回归。
  3. 判别式学 P(y|x)，生成式学 P(x) — 前者学类别边界、回答“这是什么”，后者学数据分布、回答“怎么造出这个”；生成式 AI 也不等于“无监督学习”的同义词。
  4. 奇异 ≠ 无解 — 奇异只说明方程之间线性相关：冗余时无穷多解，矛盾时才无解，要看等式右端是否相容。
  5. 阶跃激活的问题是“不可导” — 不是不够准：它的导数几乎处处为零、阈值处不存在，梯度下降拿不到更新方向。
  6. 装袋并行，提升串行 — 随机森林属 bagging（样本随机 + 特征随机），各树独立后投票或平均；梯度提升逐棵拟合前序模型的残差。
  7. 轮廓系数是内部指标，ARI 是外部指标 — 前者不需要真实标签，后者必须拿真实分组来比对，不能把 ARI 当成无监督也能算的指标。
  8. 距离聚类前必须标准化 — 距离对量纲敏感，pH 与温度各变 1 的分量并不相同；不缩放会让数值范围大的特征主导结果。
