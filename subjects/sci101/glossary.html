中文 English 释义 章节
学术诚信 academic integrity 作业须独立完成，抄袭记零并上报 Exam Office。 01
AI 声明 AI declaration 说明所用工具、目的、受影响工作、验证方式与本人修改的声明。 01
科学人工智能 AI for Science 把 AI 与机器学习用于科学研究的交叉方向，本课程的主题。 01
数据准备 data preparation 课程主题之一，处理数据质量、噪声与缺失值等问题的环节。 01
论文 essay 自选科学领域论述 AI/ML 应用的书面报告，800–1,000 词，占 15%。 01
评估指标 evaluation metrics 课程主题之一，用于衡量模型预测性能的指标。 01
实验报告 lab report 从四道实验题中择一写成的正式报告，与实验作业合计 35%。 01
数据泄漏 data leakage 测试集信息在训练或调参阶段被间接使用，使性能估计偏乐观。 02
基础模型 foundation model 经广泛预训练、可适配多种任务的模型。 02
通用 AI general AI 具备完全自主能力、可跨任务工作的 AI。 02
推理 inference 用训练好的模型对新输入给出预测的阶段。 02
窄 AI narrow AI 在限定任务上工作、能力范围有限的 AI 系统。 02
过拟合 overfitting 训练表现强而新数据表现下降，方差过大。 02
表示 representation 把每个观测转换成模型可处理形式的方式。 02
欠拟合 underfitting 训练与验证表现都弱，偏差过大。 02
分类 classification 目标为类别的监督学习任务。 03
聚类 clustering 按相似性把无标签样本分成若干簇的技术。 03
多示例学习 multiple instance learning 以“袋”为单位的弱监督方法，袋中至少一个实例为正即袋为正。 03
回归 regression 目标为连续数值的监督学习任务。 03
强化学习 reinforcement learning 通过动作与奖励/惩罚的序列学习策略的方法。 03
监督学习 supervised learning 训练数据带标签、由标签提供学习信号的方法。 03
无监督学习 unsupervised learning 在没有标签的数据中寻找结构或表示的方法。 03
弱监督学习 weakly supervised learning 标签不完整、不精确或不准确时的学习方法。 03
扩散模型 diffusion model 先对数据加噪、再训练网络逐步去噪以生成样本的模型。 04
判别式模型 discriminative model 学习 P(y|x) 的类别边界、回答“这是什么”的模型。 04
生成对抗网络 generative adversarial network 由生成器与判别器对抗训练、生成逼真数据的网络。 04
生成式 AI generative AI 利用已有内容生成新的文本、图像、音频或代码的 AI。 04
生成式模型 generative model 学习 P(x) 或 P(x|y) 的数据分布、能合成新样本的模型。 04
潜在空间 latent space 生成模型中表示数据显著特征的压缩空间。 04
基于人类反馈的强化学习 RLHF 用人类反馈做强化学习，使生成输出对齐人的期望。 04
自监督学习 self-supervised learning 从数据自身构造监督信号（如预测下一个词）的学习方式。 04
Transformer Transformer 由编码器与解码器组成、用自注意力处理序列的架构。 04
变分自编码器 variational autoencoder 用编码器压缩到潜在变量、再由解码器采样重建的生成模型。 04
行列式 determinant 衡量线性方程组各方程独立程度的量。 05
点积 dot product 两向量对应分量相乘再求和，得到一个分数。 05
梯度下降 gradient descent 沿负梯度方向小步调整参数以降低损失的优化方法。 05
超参数 hyperparameter 训练前由人设定、不由数据直接学到的量，如学习率。 05
学习率 learning rate 梯度下降中控制每步更新幅度的系数 α。 05
损失函数 loss function 把预测误差转换成一个可最小化的数值的函数。 05
参数 parameter 模型内部由训练学到的量，如权重与偏置。 05
奇异矩阵 singular matrix 行列式为零、各方程线性相关的矩阵。 05
激活函数 activation function 对加权和做非线性变换、决定神经元输出的函数。 06
Dropout dropout 训练时以概率 p 随机关闭神经元以抑制过拟合的方法。 06
早停 early stopping 在验证误差达到最小时停止训练的做法。 06
L1 正则化 L1 regularization 在损失中加入权重绝对值之和，使权重稀疏。 06
L2 正则化 L2 regularization 在损失中加入权重平方和，抑制过大的权重。 06
归一化 normalization 把特征缩放到指定范围或统一尺度，如 min-max、z-score。 06
感知机 perceptron 接收多输入、经加权求和与激活后输出二值决策的单元。 06
ReLU ReLU max(0, x)，正区间线性、负区间为零的激活函数。 06
S 型函数 sigmoid function 把实数压到 0 与 1 之间、呈 S 形的可导函数。 06
Softmax softmax 把向量转成 0–1 且总和为 1 的概率分布的激活函数。 06
装袋 bagging 对数据取随机子集、并行训练多个模型再聚合的方法。 07
决策树 decision tree 按特征做层级 if-else 提问、叶节点给出结果的模型。 07
集成方法 ensemble method 组合多个模型以得到更稳、更准预测的方法。 07
梯度提升 gradient boosting 序列建树、每棵新树拟合前序模型误差的集成方法。 07
核 kernel 把输入映射到更高维空间、使线性可分成为可能的函数。 07
间隔 margin 决策边界到最近数据点的距离。 07
随机森林 random forest 用随机样本训练多棵树、以投票或平均给出预测的集成方法。 07
支持向量 support vector 离决策边界最近、决定间隔的数据点。 07
支持向量机 support vector machine 寻找最大间隔超平面以分隔类别的监督学习算法。 07
调整兰德指数 adjusted Rand index 校正偶然一致后，聚类结果与真实分组的一致程度。 08
AUC AUC ROC 曲线下的面积，0.5 相当于随机猜测。 08
混淆矩阵 confusion matrix 按实际与预测类别交叉计数的 TP/FP/TN/FN 四格表。 08
F1 分数 F1 score 精确率与召回率的调和平均，用于平衡二者。 08
平均绝对误差 MAE 预测值与真实值绝对误差的平均值，越低越好。 08
精确率 precision TP/(TP+FP)，预测为正的样本中真正为正的比例。 08
PR 曲线 precision-recall curve 以召回率为横轴、精确率为纵轴的曲线，适合不平衡数据。 08
召回率 recall TP/(TP+FN)，实际为正的样本中被找出的比例。 08
ROC 曲线 ROC curve 以 FPR 为横轴、TPR 为纵轴、随阈值移动描出的曲线。 08
决定系数 R² 1 − 残差平方和/总平方和，越高表示解释力越强。 08
质心 centroid 簇内所有点在各特征上的均值位置。 09
核心点 core point ε 邻域内至少有 MinPts 个点（含自身）的点。 09
DBSCAN DBSCAN 基于密度连通、能识别噪声与任意形状簇的聚类算法。 09
树状图 dendrogram 层次聚类中表示合并顺序与不相似度的树状图。 09
肘部法 elbow method 对不同 K 画 SSE 曲线，取下降明显变缓的拐点定 K。 09
高斯混合模型 Gaussian mixture model 假设数据由多个高斯分布混合生成、做软分配的模型。 09
连接方式 linkage 定义簇与簇之间距离的规则，如 single、complete、average。 09
噪声点 noise point 既非核心也非边界、不属于任何簇的孤立点。 09
轮廓系数 silhouette score 衡量簇内紧密度与簇间分离度的指标，接近 1 最好。 09
谱聚类 spectral clustering 用相似度图与特征值降维后再聚类的非凸方法。 09
